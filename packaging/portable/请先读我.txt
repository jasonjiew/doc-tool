Doc Tool 使用须知（请先读我）
==================================

这一步只做一次：安装公司证书
------------------------------
双击「安装证书.cmd」，弹出的安全警告点「是」，等窗口提示完成后关闭。

作用：告诉 Windows 和安全软件，本工具由公司内部证书签名，
之后双击启动不再被拦截。

如果一键导入失败，可手动导入：
  双击 codesign.cer →「安装证书」→ 当前用户 →
  选择「将所有的证书都放入下列存储」→ 浏览 →
  「受信任的根证书颁发机构」→ 确定 → 下一步 → 完成。

正常启动
--------
双击「启动DocTool.cmd」（或直接双击 DocTool\DocTool.exe），
程序会直接从当前位置启动，主界面几秒内打开。

（1.4.4 起不再复制到临时目录启动——在装有透明加密软件（如亿赛通 DocGuard）
的电脑上，复制进临时目录的程序组件可能被加密导致启动失败，因此改为
原地直接启动。）

常见问题
--------
1. 弹出「Windows 已保护你的电脑」（SmartScreen 蓝色提示）：
   点「更多信息」→ 再点右下角「仍要运行」。安装证书后一般不会再弹。

2. 报错「Failed to start embedded python interpreter!」：
   说明程序文件在解压或拷贝过程中被安全软件破坏了。
   用「启动DocTool.cmd」启动时如果先提示
   [ERROR] Program files look encrypted or corrupted...，
   会直接告诉你是哪个文件被加密/改写了（常见 +4KB、文件头被改）。
   a) 先完成上面的「安装证书.cmd」，再重新解压本压缩包
     （安装版：重新运行安装包）；
   b) 解压后不要只把 DocTool.exe 单独拷出来——它必须和旁边的
      _internal 文件夹放在一起；
   c) 仍然报错就请 IT 把 DocTool 加入安全管理平台/加密软件白名单
     （常见于亿赛通 DocGuard、IP-guard 等透明加密客户端）。

3. 以上都试过仍无法启动：
   双击「diagnose.cmd」，等它跑完，把生成的 DocTool-diagnose.txt
   发给维护人员（王杰）；如果旁边还有 DocTool-startup.log，一起发。

一句话：整个文件夹放在哪都行，先装一次证书，以后双击「启动DocTool.cmd」。
