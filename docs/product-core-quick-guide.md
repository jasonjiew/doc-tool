# 主流程快速指南（导入 → 编辑 → 出稿 → 再次修订）

配套：[主功能优化计划](product-core-workflow-plan.md)、[易用性契约](product-core-usability-contract.md)、[兜底原则](product-flow-fallback-policy.md)、[执行台账](product-core-workflow-execution.md)。本页描述**当前已实现**的默认流程与支持范围；未实现项在文末单列，不在界面宣称可用。

## 1. 导入一份文档（默认路径）

1. 首页「新建项目…」或文件菜单「导入文档（Word / Markdown）…」（Ctrl+N）→ 选择 DOCX/DOC/Markdown。
2. 系统自动识别格式并调用对应建项服务：Word 走导入向导，Markdown 按列表顺序建**一份**项目，规范包目录走规范包建项。
3. 普通模式默认值：文档名取可信名称（否则文件名）、位置取有效默认目录、编号可空、版本默认 `1.0`；Word 保持源格式，Markdown 用通用模板。
4. 完成后直接进入编辑。已有工作区发起导入时**不切走**当前编辑，新项目在新窗口打开。

无标题样式 → 自动按单章接管全部可读正文；标题跳级 → 按整理计划补上级结构（结果中说明整理动作）；标题前正文 → 按明确范围保留为「前言」章（若只是封面图片则按底模封面处理并保留原件）。

## 2. 复杂内容与缺资源

- 格式/文本/脚注/批注/修订内容不因编辑文本丢失，原件 `original/source.docx`、记录 `original/import-record.json` 分别保持**可编辑树 / 参考文本 / 原件**；选择“原件还原”说明理由，不直接覆盖已编辑正文。
- **Word 导出 Mermaid 与代码块处理**：Word 导出默认不将 Mermaid 代码块转为图片渲染，Mermaid 直接保留为标准代码块文本排版输出，不建立临时渲染目录，无 Node/mmdc 工具链依赖。
- **图片与资源解析**：普通业务图片始终由项目实际资产根目录（如 `assets/design`）直接寻址；即便存在生成图，也采用完全独立的来源隔离解析，互不覆盖路径。
- **缺失与损坏图片**：普通模式下安全降级为占位段落 `【图片缺失或损坏: 名称】` 并记录警告，生成物仍可打开；严格模式在发现真实缺图时阻止正式登记，并给出原 Markdown 位置与诊断。
- **导出诊断与定位**：构建或校验失败时，右侧结果卡片直接呈现失败阶段、错误代码与脱敏源位置，支持一键打开原章节编辑位置及一键复制 Markdown 诊断。
- 跨页表格失败会回退到通用底模**同一张表**，失败不中断整体导出，日志保留失败证据。
- **界面工具栏布局与低频操作收敛**：
  - 顶部项目条将「导出设置…」、「快速构建」与「正式出稿」固定收纳在「更多 ▾」菜单中，多次窗口重排后不并列平铺导出设置，保留唯一的「导出 Word…」高频主操作与「成果」入口。
  - 编辑器工具栏将常用格式（标题级别、粗斜体、代码、列表、引用、表格、美化、链接、图片）按宽度排布，低频工具（表格网格、粘贴为表格、Mermaid、批量转图、片段）与文件操作（回滚、本地历史、外部打开）固定收敛在编辑器「更多 ▾」菜单中，窗口或侧栏变化不重新平铺到工具栏，只读时写入动作禁用且只读操作可用。

## 3. 出稿（Word / PDF / 离线 HTML / 源码包）

统一入口：`project-export`（CLI）或界面出稿动作。
- **界面主动作**：顶部工具栏主按钮为「导出 Word…」（Ctrl+E），主动作直接打开简洁导出设置；其它格式、规范包与高级配置收敛在「更多 ▾」菜单的「其它格式设置…」。
- **简洁设置对话框**：默认展开导出目录、文件名、导出范围、内容来源与格式选择；文档属性（DOCPROPERTY）、字段刷新细节及排版自适应项默认折叠在「高级设置」；校验错误就地红色提示，不丢失用户已填写参数；取消设置不捕获快照、不改写源文件、不清除脏标记。
- 默认设置：整份文档 + 当前编辑内容（未保存时）/ 已保存内容（已保存时） + Word + 有效导出目录。

```
doc-tool project-export --project <项目目录> [--formats docx,pdf,html,source-zip]
                        [--scope project|current-chapter|chapters] [--chapters a,b]
                        [--destination 目录] [--source-mode saved|current-buffer]
                        [--layout template|body-adaptive] [--landscape-chapters 标题]
                        [--page-break-before-chapter] [--no-refresh] [--strict]
                        [--include-original] [--retry-of export-result.json]
                        [--output human|json]
```

- 一轮出稿基于**同一份内容快照**（`captureId` 固定）：捕获后继续编辑不影响本轮结果，源文件不被改写、脏标记不清除。
- 命令行没有界面缓冲：`--source-mode current-buffer` 会被明确拒绝，默认 `saved`。
- 缺 Word：仍给可读 DOCX（状态“待刷新”）与离线 HTML，PDF 标“待转换”。
- 已生成可读 DOCX 即可打开；字段刷新/PDF 转换随后进行。
- 同名冲突采用安全新名（`名称-2.docx`）；单格式失败不影响其它已完成结果。
- 只补失败格式：`--retry-of <export-result.json> --retry-formats pdf` 使用**原轮**快照与 DOCX。
- 输出目录失效：自动回退到有效项目/用户导出目录并在结果中写明实际位置，已选范围与格式保留。
- 聚合索引：`export-result.json`（schema 1）记录 captureId、executionId、范围/来源、各格式 path/hash/status/backend/warnings 及可选 diagnostics 概要。

### 3.1 导出诊断、脱敏与恢复动作

- **全阶段诊断持久化**：每轮导出在导出目标目录的 `diagnostics/<executionId>/` 自动生成原子 `diagnostics.json`（完整机器结构，不依赖易失的快照目录；更多菜单支持打开所选导出的真实诊断记录）与 `diagnostics.md`（人类可读脱敏报告）；旧版本索引或诊断写入失败时安全降级至内存诊断，不损坏成果。
- **脱敏边界**：复制与 Markdown 报告仅保留阶段（预处理/构建/校验/Word 刷新/交付）、错误代码、脱敏路径（隐藏项目根或敏感父路径）、章节与行号；严格排除文章正文、环境变量、鉴权信息与异常内部局部变量。
- **事实恢复动作**：右侧结果卡片根据机器事实动态呈现单一主动作与次级恢复项：
  - `打开 Word`：生成 DOCX 成功且已就绪。
  - `打开 Word (待刷新)`：DOCX 已可读，但 Word 字段待刷新。
  - `定位问题`：存在行号定位时，直接跳转至正文编辑器对应文件和行，并提供返回先前光标位置能力。
  - `重试本次内容`：直接复用本次快照及已确认设置重新执行缺失/失败格式，不弹出设置对话框，不受后续活缓冲编辑影响。
  - `按当前内容生成`：预填原参数并明确按当前活缓冲来源重新打开导出设置对话框，经确认后建立新轮导出；取消则零任务、零捕获且不改写源文件。
  - `复制诊断`：一键复制白名单脱敏的 Markdown 诊断报告至系统剪贴板。

## 4. 范围、映射预设与文件批次（服务层）

- 章节范围：只纳入所选章节（按项目顺序），自动保留上级结构；范围外引用集中在结果说明。
- 映射预设：`intake-presets.json`（与模板填充配方分开存储）；失配项回退自动识别/单章并记录实际决定。
- Word 批次：一文件一项目、串行、同名安全后缀、失败/待转换项可只重试失败部分、取消保留已完成项目。
- Markdown 批次：多文件按确认顺序建成一份项目，支持资源根与底模。

## 5. 再次修订（外部 Word 修改接回）

已打开项目中选择外部修订稿 → 走既有差异重导入（预览/选择应用/冲突跳过），不新建项目、不覆盖整个项目；本轮来源作为**新来源版本**登记（`original/versions/`），旧原件不被覆盖。

## 6. 有限 Word 排版

默认**完全遵循底模**。选择「正文自适应」时只做三件有确定规则的事：普通图片按当前节正文宽度等比缩小（小图不放大）、普通表格设置列宽并重复表头、显式章前分页与章级横向（该章未形成独立节时按章前分页处理并说明）。复杂表格默认原样保留；超宽内容保留并定位提醒，不隐藏列、不裁剪图片、不任意缩小字号。

## 7. 本轮未实现 / 待验收（不要当作可用）

- 实机：Word 版式观感、字段刷新后的目录/页码正确性、冻结包（PyInstaller）出稿、断网源码包构建。
