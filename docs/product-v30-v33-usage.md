# V3.0 / V3.2 / V3.3 使用说明与限制

配套：[V3 总计划](product-plan-v3.0-v3.3.md)、[流程与兜底原则](product-flow-fallback-policy.md)、[V3 台账](product-plan-v3-execution.md)；V3.1 见 [其使用说明](product-v31-usage.md)。本页只描述**已实现并测过**的能力，未实现项在文末单列。

## 1. V3.0 正文模块与产品变体

- 模块库（CLI）：`reuse list|show|extract|import|export|install`；项目库默认 `reuse/library/`，模块为不可变版本（新版本另存，不改旧版本）。
- 固定引用：在章节正文写 ```doc-module id=<id> version=<ver> slot=<slotId>```（可带参数行与 `headingOffset`）；引用使用**项目内固定副本**，库升级不会自动改动已引用内容。
- 解析与查看：`reuse resolve` 输出来源/版本/hash/章节与行号定位；缺模块时优先同版本缓存、其次可见占位；参数缺失用声明默认或字面值；循环引用只停止该引用，其余正文继续。
- 选择性升级：`reuse upgrade` 默认只预览差异，`--apply` 才写回 `reuse/assembly.yml`；只改动选中的 slot。
- 变体与展开副本：`reuse variants|build|check|clone` 支持显式章节列表 + 文本覆盖的变体，独立目录出稿并显示实际范围；`clone` 生成**普通 Markdown 副本**（不含引用标记，可搬目录打开，供旧应用/外部作者）。
- 界面入口：内容菜单「正文模块库与引用解析…」（Ctrl+Alt+R）——列表/搜索/预览、变体下拉、解析报告、生成展开副本。
- 同源出稿：构建与快照都会在 Mermaid/资源预处理**之前**展开引用，因此预览、检查、Word、离线 HTML 使用同一份内容；使用模块引用的项目，源/重建一致性校验按“带提醒完成”处理（正式发布仍受既有审计门禁约束）。
- 限制：不做在线知识平台、脚本表达式或复杂产品配置语言；模块图片等资源按项目内固定副本解析。

## 2. V3.2 批量交付与换机正式化

- 批次计划（schema 1 JSON）：`members`/`entries` 指定项目、变体、格式、范围；`policy` 默认串行、Word 忙→待刷新、部分成功保留。
- CLI：`delivery-plan`（只读预览）、`delivery-run`（入队并串行执行）、`delivery-status`、`delivery-retry`（只补未完成）、`delivery-package`（自足包）、`delivery-promote`（换机按包内快照补刷新）。单一 JSON 报告；退出码 0=有可用结果、1=完全无可用、2=参数或输入非法。
- 界面入口：操作菜单「批量交付（持久队列）…」（Ctrl+Alt+B）——预览可执行/无效成员 → 经既有 TaskRunner 后台串行执行 → 结果页「打开首个产物 / 打开结果目录 / 只重试未完成项 / 补刷新（正式稿）」。
- 持久与幂等：队列落盘（用户或指定 store），进程重启后可 `resume`；重复入队不重复登记；取消保留已完成成员；只补未完成项使用队列内原轮快照，不重走全部任务。
- Word 占用：本应用用用户级 `word-busy.json` 标记跨进程占用（含 TTL 与进程存活校验，陈旧可接管）；被占用项转待刷新，其它成员继续。临时故障（文件占用/超时）自动重试一次。
- 自足包：包内一律相对路径，含可读 DOCX/必要源/底模/资源/报告与集合清单；不含 Git、凭据与无关缓存；包版本不符时**回退为只读/可导出可读产物**并拒绝在包内正式化。
- 限制：正式化需要本机 Word；首版不装常驻服务、不要求 CI；正式状态只由既有 `OutputState` 判定。

## 3. V3.3 本地写作辅助与可选模型

- CLI：`assist-search`（显式资料范围检索，返回出处/版本/定位）、`assist-suggest`（复用规则/术语/引用/复核/变更事实的确定性建议）、`assist-adopt`（默认只预览 before/after，不写正文）、`assist-provider`（查看可选模型状态，不含凭据）。
- 共享命令（库级）：写作辅助动作注册进 V3.1 命令注册表（`assist.search/suggest/adopt/undo/provider/overview`），CLI 与库内单测可用；概览集中提示资料范围/陈旧来源/**增强未执行**。**（第十五轮）**：应用已在 `MainWindow` 构建注册表并注册写作辅助/团队命令，「命令」菜单与命令面板都由注册表渲染，点击统一走 `handle_item`，因此“菜单、命令面板与 CLI 同 handler、同可用性”在应用内成立（V3.1 4.2、V3.3 5.3 已勾回）。
- 编辑器接线：内容菜单「资料搜索与写作建议…」（Ctrl+Alt+A）打开面板；插入走当前编辑器光标，**一次操作可一次撤销**；修订摘要候选只填既有修订记录（未打开时复制到剪贴板），不新建发布状态。
- 无模型可用：断网、超时、无凭据、坏响应都有本地候选；模型仅在用户主动点击增强时调用，凭据不入项目包，模型响应不执行命令、不当作通过证据。
- 限制：真实 provider 连通属可选试点；不做向量库/embedding 前置，不自动生成整份文档或推进评审。

### 4.2 冻结包（PyInstaller）冒烟

- 构建入口：`build_exe.ps1`（onedir 官方布局，含产物内容校验与 `scripts/tests/test_frozen_smoke.py` 冻结冒烟；`-OneFile`/`-Portable` 为可选形态）。
- 冒烟内容（`test_frozen_smoke.py`，11 项）：`DocTool.exe` 与 `_internal/` 结构、内核脚本/资源/第三方库/许可是否打包、公司模板与文档配置**不**被隐式打包、冻结态 `resource_root()`/内核可导入/第三方库可导入，以及冻结 CLI 可运行 `info`（含 appVersion）与 `--help`；产物需含 `python313.dll`、`Qt6Core.dll`、`shiboken6.abi3.dll` 且不含 `pyi_rth_multiprocessing` 钩子。（`--version` 与 V3 子命令 `--help` 属发布检查，本轮已手工执行并记录，不在该脚本内。）
- 实机提示：本机安全软件（火绒企业版）会拦截未签名 exe 从 `%TEMP%` 之外加载 DLL（`DLL load failed while importing _socket`），可用 `dist\启动DocTool.cmd`（复制到 `%TEMP%` 全新目录再启动）或把目录加入白名单。
