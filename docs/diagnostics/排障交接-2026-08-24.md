3. **本会话新证据（本机，DocGuard/IP-guard/火绒齐全）**：

   - 干净机器 #1（Administrator，无任何安全软件）：安装版同样报 193，便携包正常
   - 干净机器 #2（无加密）：同样效果

## 9. 关键坑

- 本机 DocGuard 使**同一文件的哈希随进程/时间变化**（曾见同一 zip 3 个哈希）→ 分发前在目标侧校验 SHA；构建后立即上传，不要久留
- self_heal MessageBox 在本机不弹（疑似被安全栈拦）→ 失败可见性靠新版启动器 STARTFAIL 分支
- read 工具对部分文件（app.py、test_packaging.py）误判 binary → 用 pwsh `Get-Content -Encoding UTF8` 读
- .cmd/.ps1 必须 ASCII-only（PS5.1 无 BOM 按 ANSI 解析）；cmd 括号块内 `)` 需 `^)` 转义；PS5.1 首次运行横幅会污染 stdout → 结果走临时文件
- 干净机器 TEMP 为短路径（ADMINI~1）→ 8.3 短名开启，路径差异可作为嫌疑之一（未验证）
