## 一、目标

对标市面 PDF 工具箱（iLovePDF / PDF24 / WPS PDF 工具箱 / 福昕），把 Doc Tool
补齐一套**纯离线、不依赖本机 Word** 的 PDF 工具箱，通过「工具」菜单入口 +
CLI `pdf` 子命令使用。范围不含 OCR、批注/编辑、电子签名、裁剪（文档里声明为限制）。

## 二、市面调研结论（已抓取 iLovePDF、PDF24 官网工具清单）

高频功能收敛面：

- 组织类：合并、拆分、提取页面、删除页面、重排、旋转
- 转换类：PDF→图片、图片→PDF、PDF→文本、PDF→Word（本项目已有，走 Word）
- 编辑类：文字水印、页码、页眉页脚、裁剪
- 安全类：加密（密码+权限）、解除密码
- 优化类：压缩（无损：去重+内容流压缩+去元数据）
- 元数据：查看/编辑 Title/Author/Subject/Keywords

本项目现状（v2.1.0）：互转功能已有 Word→PDF、PDF→Word、TXT/XLSX/CSV→PDF 等，
但**没有 PDF 页面级操作能力**（合并/拆分/旋转/水印/加密/压缩/图片互转等全缺）。

### 3.2 探针结论（全部在本机实测）

1. **offscreen 平台无字体库**：`QT_QPA_PLATFORM=offscreen` 时 `QFontDatabase.families()` 为空，
   QPdfWriter 画不出字。**测试与实现都必须用默认 windows 平台**（默认平台 232 个字体，
   SimSun 可用；不创建窗口即无头安全）。CI 是 Windows runner 交互会话，可用。
   GUI 既有测试（test_gui_services.py）强制 offscreen——**不要**给新测试设 offscreen。
2. **QPdfWriter 文本可被 pypdf 提取**：默认平台下 `extract_text()` 能提出中文
   （"水印测试 Hello 123"），可作测试断言。
3. **QPdfWriter 逐页自定义尺寸**：`writer.setResolution(72)`（坐标=磅）；第一页先
   `setPageSize` 再 `QPainter(writer)`；后续页顺序是 **`setPageSize(新尺寸)` 然后
   `writer.newPage()`**（newPage 在 QPdfWriter 上，不在 QPainter 上——PySide6 的
   QPainter 没有 newPage 属性！）。实测两页 595×842 / 842×595 正确。
4. **Qt 6.8 PDF 引擎完全忽略透明度**：`QPainter.setOpacity()`、画笔颜色 alpha、
   贴带 alpha 的 QImage——全部输出实色（实测 3 条路径都是 strong 像素 0 faint）。
   → **水印「透明度」用向白色按比例减淡的颜色模拟**（白底文档观感一致，且 QtPdf
   渲染/转图片链路一致）。UI 提示语写明"透明度以颜色减淡模拟"。
5. **QtPdf 渲染对 ExtGState ca<1 的内容整页不画**：实测给覆盖层注入 `/ca 0.3` 后
   `QPdfDocument.render()` 全透明（0 个非零 alpha 像素）；ca=1.0 正常。
   → 印证第 4 条：不要走 ExtGState 透明方案。Adobe/真实阅读器虽能渲染，但本工具
   自己的「PDF→图片」会丢水印，不可取。
6. **PDF→图片渲染必须白底展平**：QPdfDocument.render 出的 QImage 带 alpha 通道，
   空白处透明；直接 `convertToFormat(RGB32)` 会变黑底。正确做法：建白色 RGB32 图，
   `QPainter.drawImage(0,0,raw)` 合成后保存（PNG/JPG 都要）。
7. **加密算法**：cryptography 可用时 pypdf `encrypt(algorithm="AES-256")`；不可用降级
   `"RC4-128"` 并在结果 note 说明。权限位用 `pypdf.constants.UserAccessPermissions`：
   PRINT|PRINT_TO_REPRESENTATION（打印）、EXTRACT|EXTRACT_TEXT_AND_GRAPHICS（复制）、
   MODIFY|ASSEMBLE_DOC（修改）、ADD_OR_MODIFY|FILL_FORM_FIELDS（注释）。
8. **解密**：`reader.is_encrypted` 为真时 `reader.decrypt(pw)` 返回
   `PasswordType.{NOT_DECRYPTED, USER_PASSWORD, OWNER_PASSWORD}`。
   仅所有者锁定（打开密码为空）的文件用 `decrypt("")` 可开——`_open_reader` 统一先试空密码。
   AES 加密文件读取需 cryptography，缺包时 pypdf 抛 DependencyError——统一映射 E7003。
9. **pypdf 6.0 API 实测存在**：`PdfWriter(clone_from=reader)`、
   `writer.encrypt(user_password, owner_password, permissions_flag=..., algorithm=...)`、
   `writer.compress_identical_objects(remove_identicals=True, remove_orphans=True)`、
   （第三会话勘误：参数名是 `remove_identicals`，`remove_duplicates` 会 TypeError；
   另 `DependencyError` 不是 `PyPdfError` 子类，需单独 except。详见第三会话回写。）
   `page.compress_content_streams()`、`page.merge_page(page2, over=True)`、
   `page.rotate(degrees)`、`reader.metadata`、`page.extract_text(extraction_mode=...)`。
   **不存在/不可用**：`PageObject.add_image`、`replace_image`（→ 压缩不做图片重采样）。
10. **ContentStream 操作符格式**（若未来要做透明方案再参考）：pypdf 6 中
    `cs.operations` 每项是 `(operands_list, operator_bytes)`，操作符是 bytes
    （如 `b"gs"`），操作数放第一元组元素。本方案不用了。
11. **水印/页码覆盖层与旋转页**：源页有 `/Rotate`（90/180/270）时，覆盖层 PDF 页面
    尺寸用**未旋转的 mediabox**（与基底页一致才能 merge），绘制时先做坐标变换
    （translate+rotate）在"显示空间"画，使水印在旋转页上保持正立。变换：
    rot=90 → `translate(0,ph);rotate(-90)`；rot=180 → `translate(pw,ph);rotate(180)`；
    rot=270 → `translate(pw,0);rotate(90)`；显示尺寸 (lw,lh) 在 90/270 时互换。
    （**第三会话勘误**：原文 translate(ph,0)/translate(0,pw) 两式实测会把内容画出
    页外——显示空间四角画角标、QtPdf 渲染回采全白；上式已按探针修正。）
12. **加密环境约束**：亿赛通 DocGuard 环境下 Python 读不到 Word 生成的 PDF
    （读到的密文，报 E7001）。README 已知限制要写明：工具箱适用于非加密来源 PDF
    （浏览器下载、本工具产物、未受管进程生成的文件）；受管 Word 产物需在未加密环境处理。

    `tempfile.TemporaryDirectory()`（默认落 %TEMP%）**，绝不放仓库 tmp/ 或
    任何 D:\ 目录；这也解释了 3.2-12 的 E7001 现象与 `仅 %TEMP% 能跑` 旧结论。

### 4.2 新文件：`doc_tool/application/pdf_tools.py`（服务层，核心）

模块 docstring 注明：对标市面 PDF 工具箱的离线高频功能集，纯 Python，不依赖 Word。

**工具注册表**（id / 中文标签 / 分组 / 接受的源后缀 / 是否整批单产物）：

| id | 标签 | 分组 | accepts | 产物默认名 |
|---|---|---|---|---|
| merge | 合并 PDF | 页面组织 | .pdf（多文件整批） | `<第一个源stem>_合并.pdf` |
| split | 拆分 PDF | 页面组织 | .pdf | 目录 `<stem>_拆分/` |
| extract | 提取页面 | 页面组织 | .pdf | `<stem>_提取.pdf` |
| delete | 删除页面 | 页面组织 | .pdf | `<stem>_删除后.pdf` |
| rotate | 旋转页面 | 页面组织 | .pdf | `<stem>_旋转.pdf` |
| to_images | PDF → 图片 | 转换 | .pdf | 目录 `<stem>_图片/` |
| images_to_pdf | 图片 → PDF | 转换 | .jpg/.jpeg/.png/.bmp/.tif/.tiff/.webp（整批单产物） | `<第一个源stem>_图片.pdf` |
| to_text | PDF → 文本 | 转换 | .pdf | `<stem>_文本.txt` |
| watermark | 添加水印 | 编辑 | .pdf | `<stem>_水印.pdf` |
| page_numbers | 添加页码 | 编辑 | .pdf | `<stem>_页码.pdf` |
| metadata | 元数据 | 编辑 | .pdf | 仅编辑时 `<stem>_元数据.pdf` |
| encrypt | 加密 | 安全与优化 | .pdf | `<stem>_加密.pdf` |
| decrypt | 解除密码 | 安全与优化 | .pdf | `<stem>_解密.pdf` |
| compress | 压缩 | 安全与优化 | .pdf | `<stem>_压缩.pdf` |

分组顺序：页面组织 / 转换 / 编辑 / 安全与优化。

**数据类**（参照 `convert.py` 的鸭子协议）：

- `PdfToolSpec(frozen dataclass)`：id/label/category/accepts/plural/description/hint。
- `PdfToolOutcome`：ok/reason/detail/error_code/outputs(List[Path])/note/elapsed_seconds。
- `PdfToolRecord`：tool/source/outputs/ok/reason/detail/error_code/elapsed_seconds/position/note
  + `label`/`status` 属性 + `to_dict()`（outputs 转字符串列表）。
- `PdfToolBatchResult`：records/cancelled + total/succeeded/failed/success/error_code/
  summary()/to_dict()（对齐 ConvertBatchResult 语义）。

**主入口**：

```python
def run_pdf_tool(tool_id, sources, *, output_dir=None, overwrite=False,
                 options=None, on_progress=None, cancel_token=None) -> PdfToolBatchResult
```

- `options` 为 dict；批量语义：plural 工具整批一次执行产生 1 条记录
  （source=第一个源），其余逐文件执行（单个失败不中断整批，类似 convert）。
- 展开输入：目录一层内按 spec.accepts 收集；去重保序。
- 每个源先校验 `is_file()` + 后缀 ∈ accepts，失败落结构化记录（E7008）。
- 取消：`cancel_token.is_cancelled` 在文件之间检查，置 `cancelled=True` 停止。
- 未知 tool_id → 直接抛 `PdfInputError`。
- 未预期异常 → 单文件失败记录，error_code=E9000，detail=repr 前 300 字符。

**页码选择语法**（E7002 语义）：

```python
def parse_page_selection(text, page_count=None) -> Optional[List[int]]  # 0 基、保序去重；None/空/"all" → None=全部
def parse_page_ranges(text, page_count=None) -> List[Tuple[int, int]]   # 拆分用，保留原范围
```
- 支持 "1-5,8,10-12"（逗号/分号/空白分隔；兼容中文逗号）、单页 "3"。
- 起始≥1、start≤end、给了 page_count 时 end≤page_count，否则 E7002。
- extract/delete 必须显式选择（空 → E7008）；rotate/to_images/to_text/watermark/
  page_numbers 的 pages 可选（空=全部）。

**工具选项键（UI 与 CLI 共用）**：

- split: mode("each"|"every-n"|"range")、every(int≥1)、ranges("1-3,5-8")
- rotate: degrees(±90/180/270，-90 归一 270)、pages
- to_images: image_format("png"|"jpg")、dpi(36~600，默认150)、pages
- images_to_pdf: a4(bool，默认 False 按图片原尺寸；True 时 A4@150dpi 白底居中)
- watermark: text(必填非空)、font_size(8~200 默认48)、opacity(1~100 默认30，
  **向白色减淡模拟**)、angle(-180~180 默认45)、mode("center"|"tiled"，默认 center，
  tiled 为 3×4 网格)、color("#ff0000" 默认红)、pages
- page_numbers: position(六向，"bottom-center" 默认)、format("n"|"-n-"|"n/N"|
  "第n页"|"第n页/共N页"，默认 "第n页/共N页")、start(int 默认1)、skip_first(bool)、
  font_size(6~72 默认10)、margin(默认24 磅)、color(默认黑)、pages 不需要（全部页）
- encrypt: user_password、owner_password（缺省=user）、allow_print(默认True)、
  allow_copy/allow_modify/allow_annotate(默认False)；算法 AES-256→RC4-128 降级并 note
- decrypt: password（可空；空串先试 decrypt("")，仍失败 → E7003 提示输入密码）
- compress: strip_metadata(bool 默认 True，清 /Producer /Creator)
- metadata: title/author/subject/keywords（全 None=查看模式：detail 输出四字段，
  outputs 为空；任一提供=编辑模式写 `<stem>_元数据.pdf`）

**覆盖层机制（watermark/page_numbers）**：

1. 读源 PDF 每页 `(mediabox.width, mediabox.height, /Rotate%360)`。
2. QPdfWriter 生成同页数覆盖层（72dpi；尺寸=未旋转 mediabox；painter_fn(painter, index, pw, ph, rot)）。
3. painter_fn 先 `save()` → `_apply_orientation`（见 3.11 变换）→ 在显示空间绘制 → `restore()`。
4. pypdf `page.merge_page(overlay_page, over=True)` 逐页合并 → 写出。

**Qt 引导**：

```python
def _ensure_qgui_application() -> None  # QGuiApplication.instance() 为 None 时创建；不指定 offscreen
def _ui_font(point_size) -> QFont       # SimSun→宋体→NSimSun→SimHei→Microsoft YaHei→微软雅黑→families[0]
def _hex_color(text, fallback) -> QColor
def _watermark_color(value, opacity) -> QColor  # 向白色减淡：c*ratio + 255*(1-ratio)
```

**to_images 实现要点**：`QPdfDocument.load()` 错误枚举在 Qt 6.8 是
`Error.{None_, Unknown, DataNotYetAvailable, FileNotFound, InvalidFileFormat,
IncorrectPassword, UnsupportedSecurityScheme}`（**IncorrectPassword**，不是 Encrypted）；
渲染 `doc.render(page, QSize)`，比例 dpi/72，宽高上限 12000px（超出按比例降并 note）；
白底展平后存 PNG/JPG（JPG quality 90）；文件名 `<stem>_第{k:03d}页.png`。
加密 → E7003；个别页渲染失败跳过并 note，全失败 → E7005。

**images_to_pdf 实现要点**：Pillow `ImageOps.exif_transpose`；RGBA/P 先转 RGB
（RGBA 用白底 paste + mask，不要直接 convert("RGB")——Pillow 对透明按黑底压平）；
a4 模式建 1240×1754 白底缩放居中（resolution=150），原尺寸模式 resolution=72
（1px=1pt）；`pages[0].save(target, "PDF", save_all=True, append_images=...)`。

**merge**：≥2 个源（否则 E7008）；`PdfWriter().append(reader)` 逐个；产物名可被
options["output_name"] 覆盖；detail 报"已合并 N 个文件，共 M 页"。

**split**：range 模式输出 `<stem>_第{a}-{b}页.pdf`（单页 `_第{a}页.pdf`）；
默认输出到 `<stem>_拆分/`，显式 output_dir 时直接放其下；**先预检全部产物
再写任何文件**。

**compress**：before/after 体积对比，detail 报 KB 变化；after≥before 时 note
"该文件无损压缩收益有限"。

## 五、风险与坑（速查）

- 别设 QT_QPA_PLATFORM=offscreen（字体/渲染全无）。
- QPainter 没有 newPage；用 QPdfWriter.newPage()，且顺序是 setPageSize→newPage。
- merge_page(over, True) 水印在内容之上（市场工具同款行为，文档注明）。
- 加密/解密后 PdfWriter(clone_from=reader) 或 append(reader) 均可；AES 需 cryptography。
- compress 的 compress_identical_objects 返回值不可依赖（可能 None），detail 不引用。
- 覆盖层与旋转页：覆盖层尺寸=未旋转 mediabox；绘制前做 3.11 坐标变换。
- 转图片白底展平（RGBA→RGB32 直接转会黑底）。
- 旧版 .doc 与 PDF 工具箱无关（工具箱只吃 .pdf 与图片）。
