# V2.9 变更可追溯使用说明（工作区 / 条目 ID / 关系 / 覆盖率 / 集合基线与恢复）

本文面向使用者，说明 V2.9 新增能力的**真实用法与已知边界**。实现细节见 ``openspec/changes/product-v29-change-traceability``。

## 1. 研发文档工作区

``workspace.yml``（独立 schema 1）把需求 / 设计 / 测试多个独立项目联成一个交付集合：

- 成员路径必须在工作区根**内部**；外部项目**只能复制导入**，复制后生成新 ``projectId``。
- 合法成员（异常成员会被跳过并在 ``issues`` 里列出，不影响其余成员）：
  非法条目、未知角色、越界/绝对路径、目录缺失、项目不可读、重复 projectId/路径。
- 同角色允许多份；各文档版本**独立**，集合版本单独管理；无需求文档时覆盖率为 **N/A**（不报 0%）。
- 整个工作区目录可直接复制到另一台机器：文件内**无绝对路径**。
- 单项目仍可脱离工作区**独立打开**。

## 2. 稳定条目 ID（DOC-ITEM）

在条目行末挂一个不进正文的标记：

    系统应支持离线出稿。<!-- DOC-ITEM: projectId=... kind=requirement id=... -->

- 身份是 ``(projectId, itemId)``，**不依赖章节编号**：移动与重编号**不改 ID**，复制条目生成**新 ID**。
- 标记在渲染/预览时被剥离，**不会进入正式产物**。
- 同一 ID 出现多次会被标为重复；属于其他项目的标记会被拒绝。
- 旧编号迁移给出**可确认建议**与**歧义列表**；同号跨文档不自动写入。
  **未标记内容不会被自动计入覆盖率分母**。

## 3. 显式关系（relations.yml）

``relations.yml``（schema 1）用**显式声明**代替“按编号猜关系”：

- 类型：``satisfies``（设计满足需求）、``verifies``（测试验证）、``depends_on``（依赖）。
- 校验：重复边去重、**自环拒绝**、**悬空端点检出**、**环路检出**；损坏文件与不支持版本**拒绝而不静默丢弃**。
- 关系文件属于项目内可追踪资产，应随项目一起入版本控制。

## 4. 覆盖率与变更影响

- ``trace`` 命令：``--project`` 或 ``--workspace`` 二选一，``--format markdown|json|csv``，
  ``--fail-on-uncovered`` 在存在未覆盖需求时退出 1；参数或执行失败退出 2。
- 覆盖口径：需求分母只算已声明条目；测试覆盖含**经设计传递的间接验证**；待复核**不计入**通过。
  无需求条目时返回 **N/A**，不会出现“假 100%”。
- ``impact`` 命令：``--item projectId/itemId``（可重复）或 ``--baseline`` 快照自动比对（**无可用基线时不推断**）；
  ``--fail-on-pending`` 在存在待复核时退出 1。
- 仅**位置或编号**变化不会触发影响；**正文、标题语义或相关资源**变化会触发；
  模板/规则/术语变化作为**规范级影响单列**。影响结果**不会自动修改下游正文**。
- 复核记录保存关系两端 hash；任一端变化或端点消失后自动**重新待复核**。

## 5. 集合基线、比较与恢复

- 基线清单 ``collection.yml``记录**逐文件 SHA-256**，覆盖清单/正文/图片/表格/规范/
  规则/关系/评审/报告/正式产物；成员失败时仍产出**可用部分 + 缺失清单**（``complete=false``）。
- **严格集合交付必须显式选择**；默认不因个别成员失败而放弃整次工作。
  登记失败也**不删除已有成果**。重复版本会**另存唯一快照**并提示新版本号。
- 写入期间持有**工作区租约**（服务层强制，不依赖界面禁用）；取消会释放锁。
- 恢复**只写入新目录**，且只恢复 hash 匹配的**可信项**；目标冲突**默认换名**；
  旧格式记录（Markdown-only）标 ``legacy-partial``，**只能部分恢复**；原副本与历史只读。
  恢复后会写出 ``identity-map.json``，供关系与评审重新定向（``itemId`` 保留）。

## 6. 已知边界（请务必知悉）

1. **Word 实机环节**：正式刷新需要本机有可用的 Word。若已有 GUI Word 实例驻留，
   新建自动化实例会挂住，工具会如实返回 **E3001** 并建议改用诊断构建。
   **验收前请先关闭所有已打开的 Word 文档**（或换机）。
2. **图形界面**：矩阵分页/来源定位、关系双端编辑面板、条目动作〃已有**服务层**；
   部分界面入口仍在接入中，以 CLI 与服务为准。
3. **旧项目**：schema v1 项目**仍可读可写**，升级需用户显式选择且会先备份；
   未升级项目不受任何影响。
