# 2026-10-02 改动审查与修复

本次审查范围为当前未提交的 CORE / V3.0–V3.3 实现、界面入口、测试与配套文档。

## 已修复问题

- 模块展开后，前置校验曾把所有失败降为提醒。现在构建与校验共用展开文本，仅原 Word 基线差异允许提醒；结构、正文、图片和模板校验仍阻断。
- 快照哈希使用变体文本，物化却可能重新读取原文。现在捕获、哈希、Word、HTML 和源码包使用同一份有效正文。
- 图片曾按正文目录解析，复杂表格 XML 未收集。现在按清单资源目录和表格目录复制，并保留复杂表格标记的依赖。
- 固定模块图片引用与构建资源目录不一致。现在使用本轮临时资源目录，Word 按章节读取资源；快照也包含模块及变体图片。
- 源码包缺少父章节 `_index.md` 正文和无标题模式配置。现在保留这些内容与配置。
- 显式快照工作目录可能覆盖项目源目录。现在在删除工作目录前拒绝覆盖源项目；源码包也拒绝写入源文件目录。
- 新 CLI / 高 DPI 子进程测试覆盖了继承的 Python 搜索路径。现在保留运行器配置的依赖路径。
- 诊断构建不再无条件探测 Word；本地测试输出、依赖、审阅归档和诊断脚本已加入忽略规则。
