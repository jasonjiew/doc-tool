## 3. 页面与交互约定

沿用现有 QSS tokens、控件和布局；主动作在内容附近，次要操作进入详情/更多。技术 ID 保留可复制但不占主要视觉。关闭和返回保留草稿；跨成员/源变化只对当前动作提示，其他功能继续。背景任务显示真实阶段，不猜百分比。

| 页面 | 信息/操作顺序 | 默认动作 | 需要覆盖的交互状态 |
|---|---|---|---|
| 首页 | 继续上次工作 → 最近项目 → 新建/导入/打开 | 有有效会话继续指定章节；无会话进入建项 | 路径缺失就地重定位；空列表给主操作；当前脏缓冲保留 |
| 文档工作台 | 项目上下文 → 章节/编辑 → 问题/成果 | 写作区优先，检查/导出调用原动作 | 切章、只读、长路径、迟到事件、无 Word、未应用表格草稿 |
| 问题面板 | 严重程度/摘要 → 筛选 → 所选问题详情/定位 | 点击定位，修正后重检并返回该位置 | 加载、无问题、无筛选结果、部分结果、失败/重试、已失效来源 |
| 成果面板 | 轮次/来源摘要 → 已可用格式 → 其余格式状态/动作 | 直接打开已可用成果 | Word 待刷新、格式失败、取消后部分成功、原捕获缺失、范围失效 |
| 表格对话框 | 来源/维度 → 完整模型的分页或网格 → 就地编辑/应用 | 默认保留文本值，应用一次撤销 | 多行、空行/列、末页、源变化、重定位、取消/继续 |
| 规范制作 | 基本信息 → 资源选择/字段 → 样例/历史 → 冻结分享 | 可先保存不完整草稿，默认支持字段表单 | 未完成原文、未知键、缺可选资源、样例过期、冻结冲突、后台生成 |
| 导入/复导入 | 来源 → 章节及保留摘要 → 可应用范围 → 结果 | 普通导入用推荐设置，局部冲突单列 | 单文件失败、无标题、缺图、缓冲与磁盘双变化、保留当前/副本 |
| 出稿设置 | 来源 → 范围 → 格式 → 目的地 → 版式 → 实际摘要 | 复用上次有效选择，来源明确可追溯 | 当前未保存、选章失效、旧轮补充与当前新轮、目的地变化 |
| 研发工作区 | 工作区/成员 → 列表及筛选 → 所选详情/来源 → 下一动作 | 保留页签/筛选，按稳定身份定位 | 无需求 N/A、缺成员、只读、关系草稿、复核过期、部分成果 |

小窗口验收：1024×640、1280×720、1920×1080 下逐项测量实际文字、相邻矩形和主动作；窄时滚动/溢出，不能通过强行抬高最小宽度“通过”。深浅主题覆盖表头、滚动内容、状态与焦点。Tab/Shift+Tab 可遍历必要操作，Esc 按上下文返回，中文输入与网格编辑不被全局快捷键劫持。

## 7. 每批完成条件与执行顺序

每批要从真实按钮/菜单走到实际内容或成果；默认路径和局部兜底都验证。保存对应测试/截图/内容摘要，更新本包台账并勾真实完成项。一次相关检查通过后无需机械重复；实际新增改动或失败再扩大验证。包末执行当前默认清单或明确记录未运行范围。

旧四包的四项实机验收以及新包的实机试点可在条件具备时补；缺环境不成为独立编码前置。涉及模板正式化、团队试点和真实性能的任务不能仅以测试/规划 strict 勾完。旧原捕获缺失、范围失效、缓冲冲突等只限制对应动作，继续提供旧成果/可见设置/新轮或副本路径。
