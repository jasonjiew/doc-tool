> 预发行版本。本检查单由 ``packaging/release_gate.py`` 读取；存在「未签署」项时

- 状态约定：`待签署` = 未批准；`已签署 (日期)` = 已批准。
- 每一项都需要负责人身份与审批依据（书面授权/扫描报告/验收记录）。
