# V2.6～V2.9 流程与兜底原则

2026-09-30 按产品反馈补充。本文件与四版 proposal/design/specs/tasks 一起执行：**先得到可用结果，再集中提示需要完善的地方。默认尽力完成，严格交付由用户主动选择。**

## 1. 默认交互

- 用户点击生成、导出或应用后，自动处理有确定规则的问题；无损修复记为 info，有内容/格式缺口的兜底记为 warning，不再逐项弹窗或要求填写放行原因。
- 结果页先显示可打开的产物和下一步，再集中列出“自动处理 / 待完善 / 未执行”。状态区分完成、带提醒完成、待刷新、部分完成、失败/取消；保留事实，不将兜底说成完全保真或全部验证通过。
- 只有没有任何可用输入/底模、无法写出任何结果，或继续会覆盖未保存内容、破坏源文件/不可变历史时，停止对应操作。越界资源和非法条目跳过并定位，其他合法内容继续。
- 严格交付模式显式启用后，才把约定的内容完整性、保真和评审问题提升为门禁。严格校验未通过时仍提供安全生成的参考产物，正式登记保持待处理。
- 同名输出默认换用可辨识的新文件名；目标占用时尝试副本路径。覆盖只有用户明确选择才执行，普通出稿不为覆盖确认停住。
- 预检按生成所需解析完成，复用结果，不做额外全项目扫描或重复审批。仅对可重试且幂等的临时故障自动重试一次；失败转兜底，避免反复重试。

## 2. 必须兑现的兜底

| 场景 | 默认动作 | 结果说明 |
|---|---|---|
| 底模变化、样式映射失效 | 重新枚举样式，保留有效项；其余自动匹配已有标准样式 | 记录使用的替代样式，可生成后再调整 |
| 所选底模缺失/不可解析 | 尝试已有可用底模记忆或应用通用底模；均不可用才停止生成 | 明确实际采用的底模，不伪称保留原底模排版 |
| 部分输入缺失 | 跳过缺失项，保留其他输入的顺序；没有可读内容才停止 | 部分完成，列出跳过文件 |
| 缺图/越界资源/复杂表资源缺失 | 不读取非法路径；用资源说明占位，复杂表优先可读影子 | 带提醒完成，保留源位置和恢复入口 |
| Mermaid 超时或不支持 | 优先匹配同源码有效缓存，否则输出源码和说明 | 带提醒完成，其他章节继续 |
| 围栏、分节未闭合 | 在当前输入末尾关闭；嵌套节保留第一层、忽略重复开启 | 带提醒完成，方向不泄漏到下章；不修改源码 |
| 题注重复、引用失效 | 重复标识只在输出中分配唯一名，歧义引用保留原文/提示 | 带提醒完成，不随意猜测引用对象 |
| Word 不可用或刷新失败 | 保留已生成 DOCX 和静态可读编号/缓存值，提供之后刷新入口 | 待刷新；不撤掉可阅读产物 |
| 预设/片段/规则/术语配置损坏 | 隔离原配置并使用内置或上次有效值；非法可选项跳过 | 不阻止启动、建项或出稿 |
| 章节清单重复/缺文件、变量未定义 | 顺序去重，缺章节显示说明；变量保留字面值或已定义默认值 | 可继续编辑和出稿，源清单不自动改写 |
| 多版本历史写入失败 | 使用现有 .bak 恢复点继续保存；索引失败可由已落盘快照重建 | 历史降级提醒；无法保留当前旧内容时才停止覆盖 |
| 输出或历史登记失败 | 保存为新输出副本，保留产物路径，登记后续可补 | 产物可用但登记待完成，原正式记录保持一致 |
| 批量替换/重导入预览后内容变化 | 自动刷新受影响计划，跳过冲突项，应用其余已选且未变项 | 部分完成，保留本地内容和待处理列表 |
| 无 Git/评审有待复核项 | 修订说明用本地改动信息预填，待复核项显示在报告 | 默认不阻止编辑或出稿，严格交付才按所选规则检查 |
| 集合中个别文档不可用 | 输出可用成员和缺失清单，或保留任务开始时一致快照 | 部分集合/快照时点明确；完整基线另行登记 |
| 不完整/损坏历史恢复 | 可校验内容恢复到新副本，缺失项列清单 | 部分恢复，不覆盖当前工作副本或已有目标 |

## 3. 实施和验收

每项兜底直接接入当前服务的正常执行路径，不另建审批系统、角色认证或通用策略引擎。GUI/CLI 同源；默认可用结果含 warning 时 CLI 返回成功并在结构化报告中给出状态与问题，严格模式按所选阈值返回检查失败。

实现先跑主流程及最常见的缺图、无 Word、映射变化、坏配置，再覆盖对应写入保护和取消。无相关依赖的功能继续推进；既有无关失败和实机缺环境记入台账，不拖住全部批次。任务勾选依据实现与直接验证，未执行的检查独立记为待验收。
