## 1. 使用上的变化

1. **F5 真正检查当前正文**：复用格式检查工作台及当前活缓冲，保留实际范围/配置/来源/时点；不隐式保存全部，不拿旧 DOCX 冒充当前内容。旧成品验证保留为单独菜单入口。
2. **直接给一个可继续的下一步**：状态栏、操作菜单及建议面板基于当前事实提供离线原因和既有动作；点击前重新核对，不执行文档/模型提供的命令，不增加审批问卷。
3. **失败不丢可读成果**：Word 待刷新、部分格式失败与最终登记失败分别表达；可读文件/hash 保留。补原轮沿用原来源/捕获/范围，按当前内容生成明确是新一轮。
4. **导入问题更容易处理，但不猜测替换**：完整记录的原因/数量与分页展示分开；重开结果、筛选、原件定位和修图接同一服务。定位过期/歧义、只读、项目变化或目标有未保存编辑时拒绝磁盘替换；账本失败保留待办，不假称全部解决。
5. **资料按证据相关性优先，建议不覆盖新编辑**：先排名再截断，保留完整命中总数、中文两字/正则及陈旧提示；按文档解析物理路径、每 128 行观察取消。采纳/撤销同步最新缓冲，只更新目标并核对预期文本。
6. **AI 仍是可选附加层**：桌面主动增强先预览目标、用途、范围、截断、证据和实际 JSON，再确认发送一次；内置 HTTP 不自动跟随任何重定向，最终端点须重新预览；后台可取消、迟到丢弃。候选先展示/复制/逐条采用，不自动改正文、术语库、修订记录或批准内容。失败保持本地候选。

原有六类智能细节继续保留并回归：富文本/代码/题注导入、自然中文题注/交叉引用、章节改名/指纹与表格单元格三方合并、复杂表可编辑代理、列宽/横版/DPI、修订摘要/版本辅助。
