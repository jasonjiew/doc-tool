# Spec Delta

## Purpose

为桌面章节编辑提供接近 Typora / VS Code 的 Markdown 阅读预览，明确正文语义、排版、当前缓冲、源码定位与离线资源的行为契约，使运行时或渲染失败时仍能安全编辑并识别实际预览能力。

## ADDED Requirements

### Requirement: REQ-MD-01 标准正文语义
高保真预览 SHALL 按声明的 CommonMark 基础及表格、任务列表、删除线扩展呈现当前正文，保留段落、软换行/硬换行、嵌套列表、引用、代码块和行内代码的语义。支持范围 SHALL 可查询，不得把“兼容 Markdown”描述为兼容所有编辑器插件。

#### Scenario: 嵌套列表保留层级
- **WHEN** 正文包含有序与无序列表混合的多层缩进、列表内段落或代码块
- **THEN** 预览保留父子层级与块归属，有序列表的起始编号遵循正文，而不是把所有条目平铺为同级

#### Scenario: 连续正文行与显式换行
- **WHEN** 同一段文字由普通换行分成多行，且另一处使用 Markdown 显式硬换行
- **THEN** 普通换行不被转换为多个独立段落，显式硬换行保留为换行

#### Scenario: 行内代码保护
- **WHEN** 行内代码或围栏代码包含链接、图片、粗体标记、HTML 或 Mermaid 关键字
- **THEN** 这些内容以代码呈现，不作为链接、图片、格式或图形执行，代码原文保持可读

#### Scenario: 任务列表与删除线
- **WHEN** 正文包含已完成/未完成任务项以及删除线文字
- **THEN** 预览显示对应状态和格式，阅读操作不修改源 Markdown

### Requirement: REQ-MD-02 表格结构与对齐
高保真预览 SHALL 正确识别表格分隔行、列对齐、单元格内转义竖线与行内格式，保持正文内容和列归属。宽表 SHALL 提供横向阅读方式，长表不得因预览解析而丢失后续行或后续正文。

#### Scenario: 转义竖线不增加列
- **WHEN** 表格单元格包含转义后的竖线
- **THEN** 竖线显示在原单元格中，不把该单元格错误拆成多列

#### Scenario: 列对齐生效
- **WHEN** 表格分隔行分别声明左对齐、居中和右对齐
- **THEN** 对应列应用所声明的对齐，分隔行本身不作为数据行显示

#### Scenario: 宽表与长表完整阅读
- **WHEN** 表格超出预览宽度或包含大量数据行，表格后还有正文
- **THEN** 用户可横向查看完整列并继续阅读所有行及后续正文，列内容不被静默裁掉

### Requirement: REQ-MD-03 可复现阅读样式
高保真预览 SHALL 提供浅色和深色阅读样式，统一正文宽度、字体回退、字号、行距、标题间距、代码块及表格外观，并保留代码语言高亮能力。视觉对照 SHALL 记录参考应用版本、主题、字体、正文宽度、缩放和图形配置，不得把不同环境的截图差异直接判为内容缺失。

#### Scenario: 同一环境下对照参考应用
- **WHEN** 使用已记录的参考应用设置打开同一份验收样本
- **THEN** 预览的正文层级、列表、表格、代码及图片完整可读，外观差异有对应截图和明确判定

#### Scenario: 深浅主题与中文混排
- **WHEN** 用户切换主题或阅读中英文、标点、代码混合的正文
- **THEN** 正文与代码保持可辨识，表格和链接颜色随主题适配，不出现主题切换导致的内容遗漏

### Requirement: REQ-MD-04 当前缓冲与项目扩展
预览 SHALL 使用当前编辑缓冲和既有正文展开结果，兼容项目图片尺寸、题注/引用、模块展开、提示块及构建占位符，并保留展开内容到原始来源的对应关系。预览更新 MUST 不触发隐式保存、源码重写或项目数据格式迁移。

#### Scenario: 未保存内容立即可见
- **WHEN** 用户编辑正文但尚未保存
- **THEN** 预览在更新后显示该缓冲的内容，磁盘文件、备份和源文件编码不因预览刷新而改变

#### Scenario: 既有图片尺寸与占位符
- **WHEN** 正文使用项目已有图片尺寸后缀或构建占位符
- **THEN** 图片按声明尺寸并结合阅读宽度展示，尺寸标记和构建占位符不作为普通正文残留

#### Scenario: 模块与题注展开
- **WHEN** 当前正文包含可解析的固定模块、题注或引用
- **THEN** 预览使用与既有正文准备链路一致的解析结果，定位可回到真实来源；解析失败时保留可读原文并明确提示

### Requirement: REQ-MD-05 正文与资源访问边界
预览 MUST 不执行来自正文的脚本、事件处理器或任意本机操作。应用资源和项目引用资源 SHALL 分别按既有允许范围解析并核对实际路径；越界或符号链接逃逸资源不得读取，远程资源不得自动获取。允许的正文 HTML SHALL 经过明确的受控规则处理，不支持的内容安全展示并提示。

#### Scenario: 正文含活动内容
- **WHEN** 正文、链接或图形标签包含脚本、事件属性或可执行 URL
- **THEN** 活动内容不执行，正文仍可编辑，合法文本和允许的格式可读

#### Scenario: 合法相对图片与缺图
- **WHEN** 章节使用其文档类型资源目录中的图片，或引用图片不存在
- **THEN** 合法图片正常展示，缺图给出对应章节/行的占位和原因，不以无关旧图代替

#### Scenario: 越界与远程资源
- **WHEN** 正文引用允许目录之外的文件、逃逸符号链接或远程图片
- **THEN** 预览不读取该文件且不发起网络请求，并显示可理解的资源提示

### Requirement: REQ-MD-06 源码与预览联动
预览 SHALL 保留块级来源信息，支持点击标题、段落、列表、表格或图形定位到其源文件和源行，并支持编辑位置联动预览。展开模块的定位 SHALL 使用真实来源，不能简单把展开后行号当成当前文件行号。

#### Scenario: 重复标题与多图定位
- **WHEN** 同一章节有同名标题或多段相同图形源码，用户点击其中一个预览块
- **THEN** 编辑器定位该块对应的位置，不因只按标题文本或源码字符串匹配而跳到另一处

#### Scenario: 展开模块来源定位
- **WHEN** 用户点击由模块展开产生的预览块
- **THEN** 系统定位可用的真实源文件/行；无法定位时说明来源信息不足，不跳到错误行

### Requirement: REQ-MD-07 异步更新与阅读连续性
预览 SHALL 对编辑更新去抖，只采纳当前章节最新内容与主题的渲染结果，尽量复用未变化的块/图形并保持阅读位置。过期、切章或关闭后的结果 MUST 不覆盖当前页面；渲染期间正文编辑 SHALL 可持续响应。

#### Scenario: 连续编辑结果乱序
- **WHEN** 较早内容的渲染晚于较新内容返回
- **THEN** 页面保留较新结果，旧结果被丢弃，不回退到旧正文或旧图

#### Scenario: 更新时保持阅读位置
- **WHEN** 用户滚动到章节中部后修改附近正文
- **THEN** 预览更新围绕原阅读块保持位置，不因整篇刷新主动跳回文首

#### Scenario: 切章关闭与多窗口
- **WHEN** 图形尚在渲染时用户切换章节、关闭预览，或另一窗口更新相同文档
- **THEN** 结果仅更新其所属且仍有效的页面，不访问已关闭控件，不串到其他窗口

### Requirement: REQ-MD-08 离线成品与运行时失败
正式提供高保真模式的桌面安装版和便携版 SHALL 自带所需预览运行文件及静态资源，在断网、无 Node/npm 的终端可用。缺失运行时或渲染进程失败 SHALL 转为明确说明能力的可用降级状态，正文编辑/保存继续可用；无界面 CLI 与独立 HTML 阅读包 SHALL 不依赖桌面预览运行时。

#### Scenario: 干净机器断网启动
- **WHEN** 用户在没有开发环境、没有 Node/npm 且断网的受支持 Windows 机器运行安装版或便携版
- **THEN** 应用正常启动，高保真阅读和本变更声明支持的图形均可展示，期间不自动下载资源

#### Scenario: 运行时缺失或进程异常
- **WHEN** 高保真运行文件损坏、加载失败或图形渲染进程退出
- **THEN** 应用显示失败原因与轻量/源码查看路径，不无限重试、不丢失编辑内容，也不把降级模式标成高保真成功

#### Scenario: 既有命令行与独立 HTML
- **WHEN** 用户执行无 GUI 的现有 CLI，或在普通浏览器断网打开只读 HTML 包
- **THEN** 这些入口保留已有契约，不为使用其已有功能而强制初始化桌面浏览器或安装 GUI 预览运行时
