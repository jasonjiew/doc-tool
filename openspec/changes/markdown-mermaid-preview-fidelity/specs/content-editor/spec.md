# Spec Delta

## MODIFIED Requirements

### Requirement: 侧边 md 预览
系统 SHALL 提供随编辑内容去抖更新的侧边 md 预览（REQ-ED-01）。具备随包运行能力时默认采用高保真 Markdown 阅读模式，行为遵循 markdown-reading-preview 与 mermaid-diagram-rendering；用户 SHALL 可选择轻量模式，运行时不可用时 SHALL 明示降级。轻量模式保留标题分级、段落、表格简化呈现、图片/图形占位能力。系统 SHALL 显示当前模式及必要限制；任何模式都不得宣称与正式 Word 分页和模板版式一致。模式切换 SHALL 不修改正文、保存状态或项目格式。

#### Scenario: 打开文件显示预览
- **WHEN** 用户打开一个 .md 文件且侧边预览处于启用状态
- **THEN** 系统在侧边显示该文件当前缓冲的阅读预览，具备高保真能力时默认使用高保真模式，标题、正文、列表、表格和图片按所选模式呈现

#### Scenario: 编辑实时刷新预览
- **WHEN** 用户在编辑器中修改标题或段落文本
- **THEN** 系统在去抖窗口后更新侧边预览，反映最新缓冲内容并保持阅读位置，不隐式保存正文或用旧章节的结果覆盖当前章节

#### Scenario: 预览标注近似性
- **WHEN** 预览区域可见
- **THEN** 系统标明当前为高保真 Markdown 阅读模式或轻量近似模式；轻量模式显示近似性说明，并在各模式说明中区分正式 Word 输出的分页和模板版式

#### Scenario: 高保真能力不可用
- **WHEN** 高保真预览加载失败或所需运行组件不可用
- **THEN** 系统给出原因并提供可用的轻量/源码阅读方式，正文编辑、撤销、保存、备份及外部编辑器入口继续按既有契约工作

#### Scenario: 用户主动切换模式
- **WHEN** 用户在当前章节切换高保真和轻量模式
- **THEN** 系统使用同一当前缓冲刷新预览，保留可用阅读位置，不改写源文件，不把切换动作加入正文撤销记录
