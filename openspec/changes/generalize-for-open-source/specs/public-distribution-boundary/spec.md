## ADDED Requirements

### Requirement: 公共品牌集中且中性
系统 SHALL 从集中发行元数据获得应用显示名、组织设置键、程序标识、CLI 名和产物名称。公共 GUI、CLI、日志、安装器、SBOM、CI、发布说明与测试 MUST NOT 包含公司名称、内部产品名、公司网址或公司专用文档编号。

#### Scenario: 校验公共品牌一致性
- **WHEN** 发布检查扫描源代码、安装脚本和生成产物
- **THEN** 所有面向用户的名称与集中元数据一致，且未发现禁止的公司标识

#### Scenario: 启动公共应用
- **WHEN** 用户运行公共 GUI 或查看 CLI 帮助
- **THEN** 窗口标题、应用显示名和说明均定位为通用大型 Word 文档工具

### Requirement: 公共安装身份与内部安装隔离
公共安装包 SHALL 使用新的可执行文件名、稳定 AppId、发布者信息和中性安装目录，MUST NOT 覆盖或卸载既有公司内部版。系统 SHALL 兼容迁移非敏感用户偏好，并 MUST NOT 删除旧设置。

#### Scenario: 公共版与内部版并存安装
- **WHEN** 电脑已安装内部版且用户安装公共版
- **THEN** 两者位于不同安装目录、使用不同 AppId 和可执行文件，并可独立启动与卸载

#### Scenario: 首次启动迁移界面偏好
- **WHEN** 公共版首次启动且检测到受支持的旧设置命名空间
- **THEN** 系统复制窗口几何、主题和最近项目等允许偏好到新命名空间，不复制敏感数据且不删除旧值

### Requirement: 公共构建使用资源允许清单
公共冻结构建 SHALL 仅打包明确列入允许清单的运行资源。构建过程 MUST NOT 隐式遍历或打包仓库根 `templates/`、`config/`、`content/`、`assets/`、`analysis/` 或 `migration/legacy/`。

#### Scenario: 构建公共 onedir 产物
- **WHEN** 发布流水线执行 PyInstaller 构建
- **THEN** `dist` 仅包含程序、已批准运行依赖和允许清单资源，不包含公司模板或业务文档

#### Scenario: 未登记资源进入产物
- **WHEN** 构建产物出现未在允许清单登记的顶层资源或文档
- **THEN** 发布检查失败并报告具体路径

### Requirement: 敏感内容发布门禁
系统 SHALL 在公共 Release 前扫描 Git 跟踪文件、打包输入、冻结产物和发布文件。扫描 MUST 检测已知公司标识、内部文档编号、RFC1918 地址、内部域名、凭据模式以及非允许位置的文档与资源；发现阻断项时 MUST 返回非零退出码。

#### Scenario: 检出公司名称或内网地址
- **WHEN** 候选发布内容包含禁止的公司名称、内部编号或私有网络地址
- **THEN** 扫描失败，报告文件与规则，且发布作业不得生成正式 Release

#### Scenario: 精确允许公开夹具
- **WHEN** 脱敏测试 DOCX 位于已批准的精确路径且满足内容扫描规则
- **THEN** 扫描允许该文件，并在报告中记录命中的允许清单条目

### Requirement: 公开示例与测试数据从零生成
公共仓库中的示例、截图和测试夹具 MUST 使用虚构主体与全新内容创建，MUST NOT 通过简单替换真实业务材料中的名称来制作。兼容旧项目的夹具 SHALL 是最小人工合成数据。

#### Scenario: 审核公共示例项目
- **WHEN** 维护者检查公开示例和夹具
- **THEN** 示例不包含真实公司、客户、系统代号、设备型号、截图或文档编号，并能演示导入、编辑和构建主流程

### Requirement: 公共发布可复现且可审计
公共发布流水线 SHALL 在干净 Windows 环境执行版本一致性检查、测试、依赖审计、SBOM、敏感内容扫描、冻结构建和安装级冒烟测试，并 SHALL 生成校验和与可追溯发布说明。

#### Scenario: 生成公开候选版本
- **WHEN** 所有自动门禁和人工授权门禁均满足
- **THEN** 流水线生成版本一致的安装包、SHA-256、CycloneDX、SPDX 和发布说明

#### Scenario: 授权或许可证门禁缺失
- **WHEN** 著作权授权、主许可证或品牌批准未被记录
- **THEN** 流水线可以生成内部测试产物，但 MUST 拒绝标记或上传公共正式 Release
