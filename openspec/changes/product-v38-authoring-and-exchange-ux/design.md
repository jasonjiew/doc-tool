## Context

V3.4 已有网格和 TSV/Markdown 文本解析，V3.5 已有草稿/冻结/分享/样例，CORE 有导入、复导入和同轮出稿。当前粘贴预览只显示前 20 行，术语/规则为 JSON 编辑，从项目创建草稿默认复制顶层章节说明。复核已修复输入丢失、旧内容导出、冻结目录冲突和样例轮次混写。

## Goals / Non-Goals

**Goals:** 表格从剪贴板到可用正文更顺畅；非技术文档负责人能编辑支持的规范资源；导入/出稿的选择和结果对应所见内容；试用失败也能返回继续改。

**Non-Goals:** 合并单元格/富文本表格无损往返、任意 DOCX 对象编辑、在线模板设计器、包 schema 2、脚本规则、OCR、模型强依赖。

## Decisions

### 1. 表格预览是导航，完整模型是内容

首批 20 行提供上一页/下一页、总行数和表头开关，翻页不改变完整矩阵。网格单元格可编辑多行，统一序列化为已验证的 <br>；编辑器中的原片段锚点、显式重定位、一次撤销和未应用文本恢复复用本次修复。未支持的输入可复制原文或普通粘贴。保留 Markdown 作为唯一内容源，避免持久化第二套表格数据。

### 2. 规范资源先做选择，再做表单

“从当前项目创建草稿”显示资源清单：底模、选定骨架、变量、术语和规则；明确区分包含正文的章节副本与空骨架。默认推荐少量选定骨架，不能隐式把整个业务正文打成规范包。术语表使用 canonical/aliases；规则只编辑现有支持字段（ruleId、enabled、severity、受支持参数），未知键原样合并，复杂条目进入高级 JSON。结构表单与原文入口引用同一逻辑对象，模式切换前保留无法解析的原文。

### 3. 导入选择逐步显露

| 步骤 | 主信息 | 主动作 | 局部兜底 |
|---|---|---|---|
| 选来源 | 文件/类型/数量 | 继续 | 去掉坏文件、保留其他来源 |
| 看预览 | 章节、保留对象、缺图 | 导入可用内容 | 大纲调整、原件留存 |
| 看结果 | 项目、可用内容、需完善 | 打开项目 | 看汇总、重新定位来源 |

复导入按章节显示来源变化、缓冲/磁盘变化与冲突。默认合并无冲突项；冲突项明确选择保留当前/另存副本/应用来源，禁止全项目隐式保存。沿用原导入和合并服务，避免以界面预览替代内容比较。

### 4. 出稿设置采用一个可复核摘要

设置区按来源→范围→格式→输出→版式排序，显示实际章节数量与明确目的地。摘要从最终 ExportRequest/捕获读取；不能仅复制当前 UI 标签。结果按格式给出路径、状态和下一步；打开已完成格式无需等待 Word。原轮补齐始终使用原捕获，新正文必须显式生成新轮；失效范围回到可见设置并保留可用选择。

### 5. 样例历史复用 CORE 结果索引

每轮独立目录保存项目、captureId、roundId、draftDigest 和报告索引；已有“补原样例 Word”/“生成最新样例”继续沿用本次修复。新增历史选择与过期原因、来源摘要，让旧成果可定位。无需 Word 也能验证结构、保存和分享；诊断构建/正式刷新/视觉未验证区分展示。

### 6. 分批验收

38-A 表格交互，B 规范资源表单，C 导入和复导入，D 出稿与样例，E 从真实按钮生成可读成果、同事消费、源/缓冲摘要对照。依赖 37 的共享 UI 约定；单项可先在原界面实施，不以 37 全部实机验收为前置条件。

## Risks / Trade-offs

- [字段表单丢未知声明] → 保存前深合并已知字段，保留原文与差异用例。
- [骨架选项带入业务正文] → 在选择页展示实际含义及预览，默认不选全正文。
- [粘贴翻页导致插入截断] → UI 页与模型分离，断言最后一行及空行实际进入正文和 HTML/DOCX。
- [旧轮试用混入新资源] → 原轮入口传原索引；最新样例独立捕获和目录。

## Migration Plan

草稿新 UI 状态为可选字段，旧草稿直接加载；包 schema 1 和已有消费者不变。升级/回退不改已安装固定包，不删除旧样例目录。新增的视图状态异常只回退界面。

## Open Questions

首版不承诺复杂表格保真。真实 Excel/Word 剪贴板与 IME、企业 Word 底模验收按可用环境开展；缺环境只留该项待验收。
