## Context

参见 [proposal](proposal.md)。当前有管道表格拆分/对齐工具和普通表格预览/导出；CORE 负责普通表格宽度、跨页表头等版式。本版解决日常内容维护，避免用户在文本中手工移动大量竖线。

## Goals / Non-Goals

**Goals:** 编辑普通表格、粘贴 Excel 等来源的文本表格、可靠撤销；保持 Markdown 为唯一内容源，预览与出稿读取同一缓冲捕获。

**Non-Goals:** Excel 公式计算、合并单元格网格编辑、嵌套表格、任意 Word/HTML 富内容剪贴板无损转换、整个文档所见即所得重写。

## Decisions

### 1. 窄表格模型与明确识别范围

复用 table_format 的单元格切分/对齐能力，补充 TableModel：header、rows、alignments、原片段范围、原片段摘要。首次支持第一行表头、第二行分隔、单元格为文本及已有可表达行内 Markdown 的矩形管道表格。支持转义竖线和反斜杠，空单元格和空行尾不能丢失。非矩形输入在预览中补空格单元，保留原始输入供复制。

复杂 Word 表格保留区或无法无损表示的片段给出“查看原内容/复制内容”动作，继续使用现有编辑方式。与把所有表格强制转换相比，此范围便于验证语义保留，也不破坏原生保留资源。

### 2. 局部网格，整块一次应用

光标在普通表格内时“编辑表格”打开网格；可增删/移动行列、设列对齐、Tab/Shift+Tab 导航，保留当前选中单元格上下文。删除有内容行列通过可撤销网格操作处理，关闭前允许应用或保留待应用文本。

应用前验证源编辑器文件身份、原片段及位置。文件其他区域变化可通过唯一原片段重新定位；原表格本身已变或匹配不唯一时保留网格草稿，显示新旧差异，用户重新定位后再应用。只替换原缓冲中的该片段，用一个 QTextCursor 编辑单元支持一次撤销；不直接写盘、不清理其他草稿、不重置项目基线。

### 3. 显式粘贴表格

新增工具栏/上下文“粘贴为表格”，不拦截普通 Ctrl+V 图片和文本流程。优先读剪贴板 text/plain，使用支持引号的 TSV 解析；若是已有普通管道表格，按该模型解析。预览提供首行为表头开关、首几行、实际行列数及异常定位。

数值、日期和 `=...` 均作为字符串，保留前导零；管道/反斜杠按现有表达转义。引号内换行如普通表格渲染不能等价表达，先选择并实现可验证的换行表示；没有支持时显示转换预览及原文复制，禁止静默丢弃。只有 HTML、合并表格等不支持输入可回到原文本粘贴并继续工作。

### 4. 导出一致与性能范围

模型序列化后仍为普通 Markdown，读取已实现的预览/构建服务；CORE 有效内容捕获保留未保存表格。普通表格版式设置来自 CORE，不另造专用导出器。首版网格对 1,000 行×20 列文本样例做测量；超过舒适规模可分页预览，但导入不得截断内容。具体时间目标由同机基准定，首版要求解析不卡住 UI、结果无行列丢失。

## Risks / Trade-offs

- [反斜杠和竖线多次转义] → 建立解析/序列化往返语义测试，复用既有拆分函数并记录表达边界。
- [多行单元格表达在不同后端不一致] → 在预览与 Word 同时验证选择的表示；尚不支持时保留原文和提示。
- [打开网格后源表格变化] → 摘要与唯一定位检查；保留待应用内容，不用旧片段覆盖新表格。

## Migration Plan

只新增工具入口，不迁移历史 Markdown 或复杂表格。已有格式化按钮继续可用。去掉网格 UI 后内容仍是普通 Markdown。

## Open Questions

多行单元格可用表示需在 34-A 技术验证中确认并写入支持矩阵；不把未知渲染能力承诺为已实现。真实 Excel 剪贴板试用单列，基础 TSV 测试无需安装 Excel。
