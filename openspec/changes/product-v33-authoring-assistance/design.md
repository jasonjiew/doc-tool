## Context

项目已有章节索引、规则/术语、修订预填、评审与影响数据，V3.0 将提供模块来源，V3.1 提供待办/命令入口。无需先部署模型就能产生资料检索和规则建议。本版只给可采用的辅助结果，正式发布流程继续使用现有检查事实。

## Goals / Non-Goals

**Goals:** 作者快速找到出处、补遗漏和修订摘要；建议有范围/差异/来源，采纳可撤销；可选模型不可用时本地功能仍完整。

**Non-Goals:** 自主修改整项目、自动评审通过、自动建立追踪关系、无依据问答、后台上传、模型驱动发布门禁、向量数据库前置。按兜底原则不增加多轮调用确认。

## Decisions

### D1：本地检索先服务已有资料

用户明确加入当前项目/工作区和模块库范围，复用 ContentIndex/模块文本索引，以文本与既有术语别名检索；无全磁盘扫描、网络采集或必需 embedding。结果包含 project/module ID、路径/行或条目 ID、版本/hash、摘要和匹配原因。当前打开缓冲可作为临时来源并明示未保存。

缓存为可重建用户级数据，来源变化标过期并按需刷新；大库后台分批，不阻塞编辑。索引不可用时直接搜索已选范围内可读文本，坏条目跳过。插入先选择“带来源引用”或“复制正文”，引用重用 V3.0 固定模块/普通文字机制，不产生任意文件 INCLUDE。

### D2：确定性建议来自现有事实

首版建议只有：规范已声明但未填写的要点、术语库确定的替代提示、已有失效引用/待复核来源、修订摘要候选。调用已有检查器/审阅/影响/变更服务，不重复扫描所有内容或新增默认阻断。

每条 suggestion 含 id、kind、source/evidence、target path/range、baseHash、before/after、status、origin（rule/local/provider）和 coverage。没有依据的事实留填写提示，不虚构“需求已满足/测试已通过”。修订摘要使用当前选定变更的文件/条目/模块事实，候选可编辑后进入现有修订对话框。

### D3：采纳使用编辑器已有撤销/保存

收件区展示建议/依据/差异/应用范围，选择采纳只修改目标编辑缓冲并用一个撤销事务；保存仍走已有 ContentWriter。目标自建议产生后变化时重算对应建议，若范围冲突保留用户内容并标待处理，其他已选无冲突建议继续。采纳/忽略不自动改变 review 的通过、关系、门禁或版本号。

摘要采纳只填候选框，最终追加修订记录仍由原确认动作执行，避免重复修订。只读项目可查看建议/导出文字，不能写原文件；无需模型也可完成整条建议流程。

### D4：provider 只增强两个按钮

可选 provider 协议 `suggest_revision(context)`、`suggest_terms(context)`，返回结构化建议；实现本地模型命令 adapter 和用户配置 HTTP adapter，协议/端点格式在实现时依据实际适配目标确定，核心不绑定一家服务。默认 disabled；只有用户启用且点击相应增强动作才运行，保存/检查/出稿绝不自动发请求。

请求仅本次选择的修订片段或术语上下文，默认总长度 8000 字符，截断明示实际范围；界面显示配置目标和选定范围，单次点击即可调用，不逐条审批。凭据由用户环境变量/已有凭据能力获取，项目 sidecar、包、日志不含密钥。命令为用户预先配置的可执行文件/参数，模型文本不能改变命令或执行内容。

响应校验用途/长度/建议结构，本地 evidence ID 才可作为来源；无出处内容标措辞候选而不当事实。超时、断网、无凭据、解析失败、取消调用均返回已有本地候选并说明，默认不反复请求。provider 失败不影响编辑和交付；不将模型产物登记为已复核证据。

## Risks / Trade-offs

- [建议来源已过期] → baseHash/来源版本、按需刷新，冲突项保留用户内容。
- [索引变成昂贵前置] → 显式范围、可重建缓存/直接文本搜索，后台分批。
- [模型生成没有证据的事实] → 首版只摘要/术语，来源受本地记录校验，措辞候选需选择采纳。
- [provider 依赖拖住工作] → 无模型本地路径完整，故障自动回退，不与交付门禁绑定。

## Migration Plan

默认无需配置，项目 schema 不变。缓存/建议/provider 设置均新增且可缺省；旧项目沿用现有规则/术语/修订来源。原有 AI 提案中的 manifest 凭据/端点迁移为用户级配置建议，若执行时已有其他 provider 先适配，不重复造接口。

## 验收标准

- A33-1：当前工作区/模块检索有来源和版本，陈旧/未保存状态可识别，索引损坏仍能查当前资料。
- A33-2：没有模型可获得填写/术语/修订候选，事实来自实际数据，不凭空产生通过证据。
- A33-3：选择采纳→编辑缓冲→一次撤销→正常保存；目标变动跳过冲突且其余建议继续。
- A33-4：provider disabled 时保存/检查/出稿无网络/模型调用；两种 adapter 用 fake provider 验证接口和坏响应。
- A33-5：请求范围/截断可见、凭据不入文件/包/日志，模型响应不执行命令、不自动改正文。
- A33-6：断网/超时/无凭据回本地结果；无需真实模型账号也能完成基础验收，可选连通试点单独记录。

## Open Questions

无阻止基础开发的产品决策。实际模型地址/协议/设备性能由用户配置和试点时登记；未提供模型不阻止本地检索/规则建议或版内正常流程。
