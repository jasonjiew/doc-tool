## Why

文档原以单个 Word 文档承载，拆分为 `content/<类型>/第X章/.../X.Y.Z.md` 后已积累 300+ 个 .md 文件。Word 中 Ctrl+F 查找、Ctrl+H 替换、交叉引用导航等日常操作在拆分后无处可用：内容散落在数百个文件与目录中，"找一个词出现在哪些章节""改一处编号会不会波及别处""某章节被谁引用"全都无法直接完成。当前桌面工具只覆盖构建链路（导入/校验/合并/产物），缺少内容级的查看、检索与维护能力，拆分后的可维护性显著退化。需要在不更换 tkinter/ttk、不改变 `project.yml` 数据格式的前提下，补齐对标 Word 的高频内容操作能力。

## What Changes

- 新增**跨文件全文搜索**：按文档类型范围过滤，支持正则/大小写/整词；结果按"文件 + 行号 + 上下文预览"展示，点击定位到对应 .md 的对应行。
- 新增**文件引用关系分析**：识别 markdown 链接 `[文本](路径)` 与章节号引用（如 `3.7.10`），支持反向引用查询（选中文件，列出引用它的文件）与悬空引用检测（引用了不存在的章节/文件）。
- 新增**章节树导航面板**：左侧按 `第X章 → X.Y → X.Y.Z` 渲染目录树，点击跳转；与搜索结果、引用关系、编辑器共用承载界面。
- 新增**内置 .md 编辑器 + 侧边预览**：纯文本编辑，UTF-8 原子保存（tmp + replace），保存前留 `.md.bak` 备份；侧边提供 md 渲染预览，复用现有 build/合并链路的渲染能力。
- 新增**全局替换**：基于全文搜索索引，默认逐项确认（每条命中弹前后 diff、可跳过），"全部替换"为显式选项且先汇总预览再执行；每文件保存前 `.md.bak` 备份，替换完成后自动跑现有校验管线检悬空引用，提供一键回滚。
- 新增**章节重命名/重编号联动**：对章节文件改名或重编号时，自动扫描并提示受影响的章节号引用，确认后批量更新引用文本。
- 新增**术语/一致性检查**：检测重复标题、术语大小写不一致、TODO/TBD 残留标记，结果可点击定位。
- 复用现有 `task_bridge` 后台任务框架承载搜索/引用扫描/替换等长操作，复用 `project_service` 的项目摘要与最近项目能力，复用现有校验管线于替换后自检，复用 build/合并链路渲染能力做预览。

## Capabilities

### New Capabilities

- `content-search`: 跨文件全文检索能力——按文档类型范围过滤、正则/大小写/整词开关、结果按文件与行号展示并支持点击定位；为全局替换与引用分析提供统一索引底座。
- `content-references`: 文件引用关系分析能力——识别 markdown 链接与章节号引用、反向引用查询、悬空引用检测；为重命名/重编号联动提供受影响引用清单。
- `content-tree-nav`: 章节树导航面板能力——按章节层级渲染目录树、点击跳转、承载搜索结果与引用关系定位；不替换现有菜单与快捷键。
- `content-editor`: 内置 .md 编辑与预览能力——纯文本编辑、UTF-8 原子保存、`.md.bak` 备份、侧边 md 渲染预览（复用 build/合并链路）；与"在外部编辑器打开"兜底并存。
- `content-replace`: 全局替换能力——默认逐项确认与前后 diff 预览、`.md.bak` 备份、替换后自动校验与一键回滚；复用 `content-search` 索引与现有校验管线。
- `content-refactor`: 章节重命名/重编号联动能力——根据 `content-references` 扫描受影响引用、确认后批量更新章节号引用文本。
- `content-lint`: 术语/一致性检查能力——重复标题、术语大小写不一致、TODO/TBD 残留检测，结果可点击定位。

### Modified Capabilities

无。当前仓库尚无已同步到 `openspec/specs/` 的基线规格；本变更不改变文档构建、校验、Word 自动化与安全取消语义，仅新增独立的内容操作能力规格。

## Impact

- 主要受影响代码：`doc_tool/ui/main_window.py`（新增"内容"工作区与菜单）、新增 `doc_tool/ui/content/` 子模块（搜索/树/编辑器/引用/替换/术语面板）、新增 `doc_tool/application/content/` 服务层（搜索索引、引用解析、替换执行、术语检查）、新增 `doc_tool/domain/content_index.py`（索引与引用模型）。
- 关联代码：`doc_tool/ui/task_bridge.py`（复用后台任务承载长操作）、`doc_tool/application/project_service.py`（复用项目摘要与 contentRoot 解析）、`doc_tool/application/pipeline.py` 与校验管线（替换后自检）、`doc_tool/adapters/kernel.py`、`doc_tool/application/word_check.py`（复用 build/合并渲染做预览）。
- 测试影响：扩展 `scripts/tests/test_gui_services.py`，新增内容操作服务与 UI 状态测试；更新桌面应用人工操作检查清单覆盖搜索/引用/替换/重命名联动路径。
- 打包影响：不增加运行时依赖（md 预览复用现有 build 链路而非新引 markdown 渲染库），UI 修改完成后重新运行现有 PyInstaller/Inno Setup 构建流水线；不改 `project.yml` 数据格式与安装位置。
- 兼容性：保留现有菜单、快捷键、CLI、项目结构与合并/校验语义，无破坏性变更；新增能力仅在已打开可写项目时启用，只读项目以查看态运行。
