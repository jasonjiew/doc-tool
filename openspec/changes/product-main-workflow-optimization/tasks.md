# product-main-workflow-optimization 实施任务

MAIN-A～F，6 批/24 项。先核对已有能力与差额；复用原服务，不重做 CORE 和交互包。正常先 MAIN 后 V3.7～V3.9；已执行中的批次完成后插入 MAIN。原任务编号、已完成功能与实机待验收保持。

## 1. MAIN-A 导入质量与资源完整性

- [ ] 1.1 建立 Word/Markdown 混合内容样例及当前基准，核对标题、列表、表格、图片、链接/代码、保留对象的真实导入路径，记录已有能力与实际差额。
- [ ] 1.2 补导入解析/大纲/应用的内容对照和来源定位；默认有标题/无标题均能开始编辑，缺图或复杂对象不丢原件、不阻塞合法正文。
- [ ] 1.3 修正多来源资源身份与引用映射差额，验证 a/logo.png 与 b/logo.png、两来源 image.png、同内容复用及项目副本离开来源目录后可读。
- [ ] 1.4 从既有入口验证批量部分成功与复导入局部应用，失败只重试对应输入，活缓冲冲突保留，无关章不隐式保存；38-C 后续复用同一接口。

## 2. MAIN-B 编辑效率与章节操作

- [ ] 2.1 查找替换工作集接入当前缓冲及当前章/选章/整份范围，预览前后差异，选择应用且支持实际修改范围的撤销/恢复。
- [ ] 2.2 补常用标题/列表及显式粘贴文本整理的差额，保留代码围栏、缩进、空值与文本含义，一次动作可撤销，普通粘贴保持可预测。
- [ ] 2.3 跑通章节新建/复制/重命名/排序与确定性引用联动；复制新身份、移动保留身份，歧义引用列位置，当前未保存章不被覆盖。
- [ ] 2.4 验证批量预览后正文再次变化、保存失败和草稿重开，跳过冲突项继续其余，复用写入清单/本地恢复且导出仍能使用活缓冲。

## 3. MAIN-C 图片、图表与引用修复

- [ ] 3.1 统一图片粘贴/拖入/选文件入口到既有资源写入，相对引用与同名目标可用，插入/撤销及导出资源按实际文件验证。
- [ ] 3.2 缺图问题接通定位→选择替代→应用选定引用→重检，显示实际引用范围，默认不批量替换未选引用或删除未引用文件。
- [ ] 3.3 完善章节链接/题注/引用的有效定位与确定性修复，验证同名标题、代码中的类链接文本、跨章移动及项目副本。
- [ ] 3.4 对 Mermaid/宽图验证当前源码缓存、失败源码兜底、预览及 HTML/DOCX 内容一致；旧缓存不冒充新图，其他章节继续。

## 4. MAIN-D 检查、修复与预览

- [ ] 4.1 当前章/选章/整份检查接入真实活内容和范围，术语/编号/链接/图片/结构结果能定位，不重复报告已在缓冲修复的问题。
- [ ] 4.2 支持确定性 quick fix 的差异预览、所选应用及撤销；内容变化后刷新建议，不自动改变业务条目身份、关系复核或正式状态。
- [ ] 4.3 补预览/检查的去抖、代次和生命周期差额，验证快速输入→切章→返回及关闭视图，最新正文正确呈现且旧事件不污染新章。
- [ ] 4.4 复用增量索引测量常用检查/预览热路径，至少5次采样，对照完整扫描和缓存损坏兜底；性能改善以真实台账说明，不减少检查内容。

## 5. MAIN-E Word 排版与出稿质量

- [ ] 5.1 用当前底模/样式/版式服务核对实际映射和正文边界，补有效默认及回退差额，保留封面/页眉/页脚和复杂对象支持契约。
- [ ] 5.2 优化支持的标题/列表、普通表格宽度/长表表头、多行空值、宽图、代码/链接，保留前导零与文本；通过实际 OOXML/HTML 和内容对照验证。
- [ ] 5.3 验证整份当前内容的快速默认、显式选章及同轮 DOCX/PDF/HTML/源码资源一致性；旧轮补齐保持原捕获，CLI 文件输出含义不变。
- [ ] 5.4 补目标占用/不可写、单格式失败/无 Word 的真实续行差额，尝试有效副本目录或文件，保留已有可读成果并显示真实状态，不伪报正式成功。

- [ ] 6.2 执行 Markdown多来源→同名资源→范围替换→复导入局部冲突→副本离线出稿闭环，运行直接相关回归并记录当前默认清单实际覆盖。
