## 1. 41-A 本地企业模板目录

- [ ] 1.1 盘点并复用现有规范包、DOCX 底模、RecipeStore 和导出预设，建立可重建本地目录引用；按骨架建项、模板填充、项目出稿区分实际用途。
- [ ] 1.2 支持按名称/用途搜索和最近使用，详情读出真实来源、版本/内容摘要和兼容信息；同名模板不按显示名合并，固定包只生成制作副本。
- [ ] 1.3 实现空目录有效默认、缺路径重定位及坏索引局部回退；其他条目照常使用，原模板/包/未知声明保持。
- [ ] 1.4 从现有规范/模板入口接入列表与详情，验证加载、空、无结果、缺失、只读和回退状态及回到原上下文。

## 2. 41-B 可复用设置与有效默认

- [ ] 2.1 沿用现有 recipe/导出设置保存模板引用、实际样式映射、已支持 LayoutProfile 字段及格式，兼容旧记录和未知元数据。
- [ ] 2.2 对实际底模样式 ID 与消费者支持字段核验映射/设置，保留有效项并显示替代摘要；未支持声明保留详情但不声称已应用。
- [ ] 2.3 将正文来源/结构化范围与模板预设分开，普通快速导出默认整份当前内容；template-fill 的输出仍为 DOCX 文件路径，换目录不丢所选范围。
- [ ] 2.4 验证保存/重开/重命名/删除预设、失效样式与损坏配置回退；当前活缓冲、原 recipe 和历史捕获不被隐式改写。

## 3. 41-C 真实底模的隔离小样

- [ ] 3.1 用所选真实模板及设置生成独立通用小样，覆盖标题列表、长表/多行、宽图、代码和已支持字段；沿用原样例服务和 V4.0 后台适配。
- [ ] 3.2 展示实际底模、应用/替代参数与可读成果；HTML 内容预览、Word 待刷新和真实分页视觉分别标示，无 Word 仍可继续试用。
- [ ] 3.3 小样复用按模板内容摘要、映射、版式及样例内容失效，每轮目录独立；旧样例补 Word 使用原报告/捕获，新设置明确生成新轮。
- [ ] 3.4 默认小样不带业务正文，仅在明确选择片段时复制到隔离目录；验证取消、占用、单格式失败和重开不会覆盖当前项目与旧样例。

## 4. 41-D 更换模板与常用交互

- [ ] 4.1 更换前显示旧/新模板真实身份、有效/失效映射、受支持版式变化及保留部件边界；应用只改变所选配置及后续明确新轮。
- [ ] 4.2 在列表详情提供试用小样、使用此模板和最近成果，高级映射按需展开；当前项目出稿无需进入规范制作或填写全部高级项。
- [ ] 4.3 保持制作草稿、未知资源、未保存正文和导航返回；固定包需要编辑时自动进入可编辑副本，不原地修改历史包。
- [ ] 4.4 验证搜索/切用途/缺失模板/试用中/部分结果及 1024/1280/1920、明暗主题、Tab/Esc/长名称，主动作可达且支持滚动/溢出。
