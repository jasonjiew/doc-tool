## Context

当前桌面用 PySide6，中心 TabsHost / EditorPanel、章节树 Dock、TaskDock 和高级面板已存在。上一轮 UI 功能已实现，独立人工验收项仍单列。新规划基于 `2e5be72` 工作树和显式注册中文字体的隔离控件截图，详见 [产品计划](../../../docs/product-ui-experience-next-plan.md)。

现有 `styles.py` 已集中字号、颜色、间距、按钮角色；`WorkbenchState` 提供动作可用性；最近项目已有搜索；`SessionState` 已存布局、标签、滚动、预览。`ExportRequest`、`ExportScope`、`LayoutProfile` 和原出稿/重试/队列负责业务。UI 不复制这些状态机。

## Goals / Non-Goals

**Goals:**

- 1024 主窗口和 340px 面板下主要动作可读可达，正文空间更合理。
- 从检查/搜索/资料定位后可返回原位置，调整阅读不修改正文。
- 用既有服务完成 GUI 多格式、范围、来源和有限版式设置，普通导出不增加门禁。
- 结果与历史展示事实，可选失败有继续路径，旧轮重试身份可核对。

**Non-Goals:**

- 不重建导入/出稿/队列、关系、评审、模块、模型或表格引擎。
- 不替换 Qt 工作台为网页，不强制迁移用户布局，不引入云端数据。
- 不把近似预览做成 Word 精确排版，不把历史视图缓存做成正式状态来源。

## Decisions

### 1. 在现有动作和样式上收敛

菜单、项目条、更多、命令面板共享 QAction/handler 和原可用性，避免每个按钮另设快捷键。移除重复快捷键绑定时保留可见入口。项目条按 availableWidth 与完整样式后的 sizeHint 决定动作溢出；文字可省略的只限名称/路径，主动作不裁切。响应 resize/style/font 变化，不在 resize 中递归重建界面。

继续使用 `btnRole`、`statusTone`、现有字体/间距 token，新增共享提示/空态/表单样式，渐进替换硬编码。Qt/资源图标有文字兜底。考虑过固定二排项目条和全新左侧应用导航；前者挤占正文，后者扩大改动并与 RD 导航重叠，本轮采用可折叠细节与动作溢出。

### 2. 本地偏好兼容扩展

最近项目固定/筛选存在既有个人配置域，项目会话的光标、阅读字号、视图选择扩展 `SessionState` 的可选字段。旧字段继续读取，缺失/错型字段按项回退，未知字段读取不影响工程；写入只用原原子保存方式。只读项目用现有个人配置位置保存个人偏好，不强写项目。

首页“继续”调用既有打开与草稿恢复，不制造第二份恢复记录。表单便利默认和快捷 Word 默认分开：快捷 Word 永远整份/current-buffer/Word/模板/非严格；设置不持久保存 strict=true、当前捕获 ID 或失效范围为静默默认。

### 3. 位置历史只存导航

在 ContentWorkspace/TabsHost 之间设置轻量导航协调器，记录项目身份、相对路径、光标、滚动、导航来源；会话内上限 50 条、重复相邻位置合并。后退/前进重放有 suppression 标记，不二次入栈；新主动跳转清空前进支路。跨项目清空/隔离，关闭文件后可重新打开但不能覆盖已有脏 EditorPanel。已删除目标就地说明，可跳到上一有效位置。

主动导航源包括章节树、标签选择、项目搜索、问题、资料来源；源代码预览已有定位复用。历史不逐键记录，不存正文，不恢复一个旧文本快照。面包屑读取真实路径，重命名走既有事件更新。考虑过所有来源各自保存“返回”，会产生多套光标状态，故统一导航事件。

阅读视图复用当前预览/目录/专注模式和 Dock 布局快照，临时切换与用户永久布局偏好区分。缩放通过编辑器/预览字体或文档默认字体，不修改正文 QTextCharFormat/Markdown，避免混入撤销或出稿。

### 4. 导出表单只是请求适配器

新增 ExportSettingsDialog（名称可按工程惯例调整），字段绑定已存在 `ExportRequest` 与 `LayoutProfile`。纯 adapter 将字段映射为请求，窗口线程提交时读取当前缓冲，原 TaskRunner 调用 `run_project_export`。不在 GUI 线程做构建、Word 检测、转换或全项目扫描。

基础区域是格式、范围、来源、目录/名称、版式；高级折叠。章节列表复用当前索引，按文档顺序提交；索引仍加载时可导出整份。空勾选沿用 CORE 整份回退，界面同步显示实际策略并提供重新选择，不新增强制确认。有限版式只映射真实支持字段；格式不适用选项明确标注，不生成假 Word 分页预览。

按当前再生成/换设置打开同一表单，带入原格式、结构化原范围和目录，用户看到再提交新轮。需要在 `ExportRoundView` 增加可选原请求/范围字段时，从真实报告读取，不从 scope_text 反解析。快速 Word 使用独立安全默认，不依赖上次高级选项。

导入完成摘要复用原 intake report 与工作台反馈，不阻挡进入项目。错误提示保留原错误码/技术详情，普通模式自动回退后的实际事实进入结果，不能改为“完全保真”。

### 5. 历史引用与权威报告分开

原 RoundStore 会话列表仍使用；通过既有会话/个人偏好保存最多 12 条轻量历史引用：roundId、captureId、createdAt、项目、结构化范围、生成时摘要、文件路径/已有摘要、报告位置。不得复制正文、产物或无界日志。历史缓存只提供“生成时记录”，当前文件可用性和正式状态分别向既有文件/报告/OutputState 查询；仅文件存在不能升级正式完成。

读取磁盘报告必须同时匹配所选 roundId/captureId，捕获失效时禁止补原轮并给新轮导出入口。尤其同目录 `export-result.json` 会被新轮更新，绝不能把这个文件路径的最新内容当作任意旧轮报告。若既有 V3.2 已有逐轮持久引用，优先复用；否则历史项可读/定位，但原轮重试仅在可核对报告与捕获存在时开放，不新造任务协议。

缓存坏项只跳过该项，最新报告仍可加载；清空历史仅清偏好，不删文件/捕获/任务。历史路径不能反向写工程。检查耗时的摘要/状态更新使用现有后台路径，迟到结果按项目和选择代次归属。

### 6. 面板根据宽度改变布局

成果/辅助 340px 可竖排动作或主动作+更多，420/700px 按实测自然展开。长路径默认折叠，正文解释换行；可滚动内容与底部提交动作分离。批量成员用同一列表模型展示名称/路径/可执行原因，保留现有 parse_plan / batch schema 1；模块库与建议采用相同上下文条和详情结构，不改变版本/采纳协议。

## Risks / Trade-offs

- [动作迁移使老用户难找] → 原菜单/命令仍可用，宽屏保留高频次级动作，更多项顺序稳定。
- [视图切换重置用户布局] → 记录进入前快照，退出恢复，显式永久布局选择仍由旧 session 控制。
- [导航重放触发外部刷新或覆盖脏缓冲] → 优先复用打开的 EditorPanel，既有脏缓冲/外部修改处理保持，历史只还原位置。
- [历史索引被覆盖导致补错轮] → 双 ID 核对，匹配失败降为仅历史查看，并直接提供当前内容新轮。
- [更多设置增加操作成本] → 一键 Word 默认保持，表单默认可立即提交，高级折叠。
- [模拟缩放误当实机验收] → 证据必须注明平台、字体、逻辑 DPI、requested/actual geometry；真实 Windows、IME、Word 单列。

## Migration Plan

按 UI2-A→B→C→D→E→F 渐进改控件，每批直接场景验证。只增加可选个人/会话字段，不迁移 project.yml 或既有任务/产物 schema；旧配置可加载。回退可忽略新增偏好字段，原菜单/导出服务保持可用。只读和损坏偏好回退默认，不强迫迁移才能打开项目。

## Open Questions

- 真正的 Windows 125%/150%、跨屏和中文输入法效果需实机；无环境记录对应项，其余正常推进。
- 实施开始需核对 V3.2 逐轮报告可用位置与最近新的工作树变化；有真实引用即复用，没有则按上述受限历史策略，不扩大持久队列协议。
- 真实企业长名称/模板样例可在人工试用中补充；本包先使用可复现合成样例和默认值，不等待外部样例才编码。
