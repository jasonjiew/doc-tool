# RD 研发工作区界面集成任务

6 批/24 项；依次 RD-A→B→C→D→E→F。沿用已有服务；RD-E 新捕获/出稿依赖 CORE，已有集合查看/恢复可先做。每批实施时执行相关入口与状态验证，不能只测服务就算界面完成。实际状态以勾选及证据为准。

## 1. RD-A 基准与适配

- [ ] 1.1 固定实际 HEAD/工作树及三成员最小工程样例，核对已有服务、CLI/GUI 入口与归档遗留，记录可复现基准。
- [ ] 1.2 复现高 schema 只读测试，确认 schema 1 固定替换问题后修正真实不支持版本夹具，验证只读保护仍有效。
- [ ] 1.3 复现 Mermaid GUI 状态失败，区分语法、渲染与源码兜底，修正可确认的问题并记录实际环境限制，禁止伪造成功。
- [ ] 1.4 实现工作区视图薄适配和统一来源定位结果模型，用已有服务对照身份、缺失项、来源模式与错误结果。

## 2. RD-B 工作区、概览与设置

- [ ] 2.1 增加创建/打开/保存工作区及引用/复制/移除/重新定位成员入口，验证重开持久化和角色/项目身份语义。
- [ ] 2.2 接入项目概览与下一步操作，空工作区、缺成员及过期报告可解释，单文档仍能直接编辑出稿。
- [ ] 2.3 基于 load_settings/save_settings 增加样式/变量/术语/支持规则分组，当前分组保存及字段错误定位验证通过。
- [ ] 2.4 接通成员跳转与窗口激活，验证跨项目定位、未保存缓冲保留及高 schema 项目禁写。

## 3. RD-C 条目与关系

- [ ] 3.1 接入声明/复制/显示稳定条目动作，复用 item_actions，通过编辑缓冲一次撤销并验证复制 ID。
- [ ] 3.2 实现双端条目检索与类型选择，展示成员、章节、摘要和真实来源，不按编号猜测关系。
- [ ] 3.3 接入关系保存/删除与重复幂等处理；未保存端点提供草稿及仅保存相关两端的动作，验证无隐式全项目保存。
- [ ] 3.4 验证重编号、重复 ID、悬空端点、来源变化和只读成员的界面反馈与定位，保留普通编辑/导出可用。

## 4. RD-D 矩阵与影响复核

- [ ] 4.1 接入 build_matrix_page、未覆盖筛选、分页和来源跳转，显示显式需求分母、直接/间接覆盖及 N/A。
- [ ] 4.2 接入变化/影响路径/待复核列表，标明已保存或 CORE 捕获来源，并验证 CLI 与 GUI 同源报告一致。
- [ ] 4.3 适配现有版本化复核服务，绑定真实已保存摘要，支持过期/变化重检和缓冲复核草稿，禁止自动升级为通过。
- [ ] 4.4 完成真实 GUI 三成员关系→矩阵→变化→复核场景，验证无需求、孤立条目及打开后再次变化的结果。

## 5. RD-E 版本集合与成果

- [ ] 5.1 接通集合列表/详情/差异/导出包及成果打开，直接复用 collection_ops，不创建第二种清单语义。
- [ ] 5.2 通过 CORE 不可变捕获与出稿接口协调本轮成员输出，Word 串行，逐成员状态按实际 OutputState 更新。
- [ ] 5.3 接通缺成员、单成员失败、无 Word 和取消时的部分成果、清单及重试，已完成文件立即可用，不另造持久队列。
- [ ] 5.4 接通恢复为副本，验证部分恢复/摘要不符/目标冲突及当前源文件和缓冲不被覆盖。

## 6. RD-F 验收与交接

- [ ] 6.1 执行单文档和三成员研发闭环自动集成验证，覆盖身份、来源跳转、关系持久化、矩阵和集合恢复。
- [ ] 6.2 执行无 Git、无 Word、缺成员、坏配置和未保存内容场景，记录可用/待完善结果及未完成事项。
- [ ] 6.3 验证 1280×720 逻辑窗口及键盘可达，执行可用的真实桌面/Word 试点；环境缺失部分明确待验收，不冒充完成。
- [ ] 6.4 更新功能清单、使用说明和独立执行台账，完成相关回归及 OpenSpec strict 校验，记录实际完成/遗留而不重置旧任务。
