## ADDED Requirements

### Requirement: 章节提交历史与当前比较
系统 SHALL 异步显示章节 Git 提交历史、可获取的重命名链和历史正文，支持与当前未保存缓冲的只读比较；历史缺失范围 MUST 明示，原提交不改。

#### Scenario: 重命名后查看历史
- **WHEN** 章节经历两次提交及重命名后打开历史
- **THEN** 可获取记录按时间显示，选中版本与当前内容比较，作者/时间表示提交来源而非当前编辑归属

### Requirement: 本地历史兜底与恢复
系统 SHALL 在 Git 不可用/无记录时显示可用本地历史；选取旧内容保存经原 ContentWriter 创建新保存，Git 历史保持不变。

#### Scenario: 非 Git 项目恢复历史
- **WHEN** 项目无 Git 但有本地保存记录，用户选择旧内容恢复
- **THEN** 历史可查看，恢复成为新的受保护保存，当前内容有恢复点且其余编辑流程不被阻断
