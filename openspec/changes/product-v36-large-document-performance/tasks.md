5 批/20 项，36-A→B→C→D→E。C 装配集成依赖 V3.0；普通项目部分可先做。目标依据同机实测，不凭单次耗时宣称完成。

## 1. 36-A 性能基准

- [x] 1.1 建立 50/300/1,000 章节含表格/图片/条目的确定样例，记录输入摘要及机器环境。
- [x] 1.2 为打开、首屏、预览、检索、检查及出稿阶段补可选计数/耗时/内存观测，不记录正文。
- [x] 1.3 同机冷/热各执行至少 5 次基准并报告分布，识别真实重复解析、线程阻塞与内存瓶颈。
- [x] 1.4 确定目标热路径，记录设计中的解析次数/耗时/小样例退化目标及有证据的调整理由，保留直接读取对照。
