## Context

2026-10-02最终复核，依据[调研](../../../docs/product-ui-interaction-research.md)、[最终计划](../../../docs/product-ui-interaction-final-plan.md)及实际工作树。CORE/V3勾选快照151/157，本包起始0/20。已有TaskDock/ResultState、TaskRunner、SessionState和报告索引，复用这些实现补界面差额。

## Goals / Non-Goals

**Goals:** 导入后直接写、默认正文空间充足、快速Word可发现、结果持续可查、高级能力有首用路径。默认尽力完成，局部问题有下一步。

**Non-Goals:** 更换UI框架、重写解析/捕获/导出/队列/模块引擎、制作全部RD界面。研发成员/关系/矩阵归RD，表格网格归V3.4。本包例图使用模拟数据，实施验收使用真实Qt控件和文件。

## Decisions

### 1. 入口及主操作沿现有上下文

改EmptyState/ProjectBar：首页主区拖放与按钮共用intake路由，转换卡保留独立语义。DOCX按已有逐份建项、Markdown按显式顺序组稿；已打开项目接外部修订沿ReimportService，保留原未保存处理，不自动切走脏标签。显示实际采用的路由和结果，不创造另一多输入协议。

顶部“导出 Word”接现有quick export；菜单、按钮、Ctrl+E共用handler及可用性。默认整份/current-buffer/有效目录，显示未保存数量，不继承旧部分范围/saved/strict。无Git或Word不额外阻断可读稿；只读项目沿现有外部出稿，真正写源的保存动作单独说明原因。运行中只限制冲突发起，编辑/查成果仍可用。

导入只突出“开始导入”，高级章节/映射可发现，普通有效源已选后最多2次主要提交。保留预检决定、原件和失败/取消输入；普通成功不追加确认页。

### 2. 首用布局与用户偏好分开

格式工具栏用Qt原生溢出或实测可用菜单，标题级别可选，14个原动作均有找回路径；长路径省略可复制完整值，格式/状态按宽度重排。

有效旧会话优先恢复。缺失/损坏会话使用章节树+正文的首用默认，摘要折叠、大纲/预览按需、空闲底部/任务面板收起。普通后台事件不关闭用户主动打开的面板；任务可提供状态入口，不强迫大面板弹开或抢焦点。

“恢复写作布局”只重设布局显隐/尺寸；主题、标签、光标/滚动、正文及草稿保留。实现沿SessionState/已有恢复链路，必要可选字段有缺省，不另造偏好文件。

固定实际逻辑窗口1280×720，默认单栏正文控件至少560×320；1024×640关键动作可读可点。全展开面板单列。首页旧DPI检查的非零尺寸/窗内几何不能代替打开项目后的正文和文字验收。

### 3. 成果扩展既有视图和报告

扩展TaskDock/ResultState或其内容页，适配导入、ExportReport及delivery gui_hooks报告；按项目/轮次/成员/格式显示真实来源及可用路径。无产物的普通命令显示摘要/详情，普通完成非模态，必要的未保存/覆盖决定保留。

当前会话保留最近轮次，重开沿已有export索引/delivery result_index恢复。如最新索引会覆盖历史，最小补充按轮次保留原报告或引用目录索引，列表设置合理上限。报告是历史事实，正式登记仍由OutputState/集合判定，UI不能升级其权威状态。关闭成果不删除结果；切项目只展示本项目，迟到结果归原项目，不激活或覆盖新界面。

逐格式打开前检查真实路径，失效给重新定位/重新生成；不能拿上一轮同名文件冒充本轮。

### 4. 三种恢复动作来源明确

| 动作 | 来源 | 轮次 |
|---|---|---|
| 补这次成果/目录页码 | 旧捕获及原范围/来源 | retry_export_formats/既有补刷新，保持captureId |
| 按当前修改重新生成 | 发起时新收集的current-buffer | 新captureId/轮次，使用显示的格式/范围，不隐式读旧saved内容 |
| 换目录并重新导出 | 设置中明示来源/范围，默认当前内容 | 新轮，旧轮保留；仅选目录不启动，取消选择保留结果 |

全部长操作走已有TaskRunner/持久队列和安全取消，Word仍串行。请求附项目/轮次/任务关联；忙时先拒绝重复启动再更新展示，不能清空运行中任务。UI线程采集缓冲再交后台，工作线程不读Qt控件。

接真实阶段/产物就绪信息；若只有结束报告，补最小就绪事件/报告适配，使可读DOCX生成即可打开。不靠文件存在猜正式状态。取消保留已完成项；不能安全中断的Word阶段显示等待安全边界。普通完成不抢焦点，局部错误给动作，技术信息按需。

### 5. 高级功能形成最小首用闭环

批量交付新建表单和打开已有计划并列，表单经delivery.contract.parse_plan校验原batch格式，用gui_tasks.plan_preview/run_plan_task和已有队列执行。只加成员/现有变体/格式/目录输入与合法保存薄适配。合法成员继续，全部无效时保留表单并给定位/移除原因。

模块调用reuse_commands.extract_chapter_module及install_modules：创建明确缓冲/保存来源，空当前缓冲不读旧磁盘正文冒充；先选择/配置已有库，安装明确版本，再沿canonical固定引用/正文和一次编辑器事务插入，资源可解析、一次撤销。只读可预览/复制，不新增在线市场。

AssistPanel资料/建议切页，共用出处/差异详情，保留搜索/插入/采纳/撤销、已有建议导出及provider配置。无范围给实际设置动作；provider未启用折叠模型动作，本地功能继续。项目/选中项变更后旧结果不覆盖详情。

### 6. 键盘和反馈按上下文工作

Ctrl+F当前章、Ctrl+Shift+F项目全文；编辑器焦点Ctrl+B/Ctrl+I格式动作，分支保留无冲突入口，菜单/注册表一致。其他输入框正常编辑不受全局格式动作拦截；Qt组合输入事件验证和真实输入法5.3分开。

帮助等入口可聚焦。Esc先关闭当前临时层，回触发位置；不会同时关闭层并取消任务。任务取消沿明确入口和安全逻辑。普通局部问题分“自动处理/待完善/该项失败”，先列最多3个可行动问题；strict显式选择。

## Risks / Trade-offs

- 旧偏好被覆盖：有效会话优先，显式恢复布局，分别验收。
- 补缺混入新正文：旧捕获与新轮分开，验证captureId/缓冲/磁盘事实。
- 最新索引覆盖历史：按轮保留报告引用或副本，UI索引不替代正式状态。
- 只替换模态测试即宣称可用：保留原业务/来源断言，增加真实控件、焦点和打开路径验证。
- 环境缺失拖停：仅直接受影响项待验收，其他继续；不弱化数据/来源断言。

5.3缺真实环境保持未勾选，继续5.4；最终区分自动可用与实机未完成。新增测试登记已有runner，最终整合后执行一次全量，OpenSpec strict单列为结构检查。无需等旧包归档或全部人工试点结束才开始UI。
