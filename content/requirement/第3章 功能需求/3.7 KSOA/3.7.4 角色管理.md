#### 新增修改

<!-- TBL:style=43 type=auto tw=0 trh=485 cols=1582,1395,1665,2415,2797 cm=0,108,0,108 ind=0:dxa lay=fixed bd=single:auto:4:0 va=center -->
| 需求标识 | 描述 | 数据类型 | 输入限制 | 验收标准 |
| --- | --- | --- | --- | --- |
| REQ-OA-2810 | 角色名称 | 文本输入框 | 必填，唯一性校验，3~20个字符 | 用户必须输入唯一的角色名称。 |
| REQ-OA-2811 | 角色标识 | 文本输入框 | 必填，唯一性校验，大写英文和下划线，3~20个字符，修改为禁用 | 用户必须输入唯一的角色标识。 |
| REQ-OA-2812 | 角色描述 | 文本输入框 | 可选，3~20个字符 | 用户可以输入角色的描述信息。 |
| REQ-OA-2813 | 数据权限 | 下拉选择框 | 必填 | 用户必须选择角色的数据权限级别。 |
|  |  |  |  |  |

数据权限选项如下：

- 全部: 允许角色访问当前租户的所有数据，不考虑组织间的数据隔离。

- 本级和子级: 允许角色访问当前用户所属组织及其所有子级组织的数据。

- 本级: 允许角色仅访问当前用户所属组织的数据，不包括任何子级数据。

- 自定义: 允许管理员为角色自定义特定的数据访问规则，可跨组织树进行数据访问设置，没有组织层级的限制。
