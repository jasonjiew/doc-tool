| 功能描述 | 将设备测量的数据按每次做做的项目组合生成体检报告。 |

<EMPTY_PAR/>
<!-- TBL:style=43 type=auto tw=0 cols=1524,8330 cm=0,108,0,108 ind=0:dxa lay=autofit bd=single:auto:4:0 -->
| 功能概览 | 功能描述 |
| --- | --- |
| 列表 | 展示筛选后的测量数据列表，包括居民信息、设备信息、测量项目等。 |
| 搜索 | 通过各种条件筛选测量报告列表，包括姓名、身份证号、创建人、报告类型。 |
| 查看体检报告 | 允许用户查看选中体检报告的详细信息，展示各项检测结果及其参考范围。 |
| 打印体检报告 | 允许用户打印选中的体检报告，并根据是否需要医生签名进行显示。 |
| 测量项目 | 展示测量项目测量值的正常范围区间 |
