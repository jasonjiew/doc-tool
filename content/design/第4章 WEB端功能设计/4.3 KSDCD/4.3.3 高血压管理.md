#### 核心逻辑

<!-- TBL:style=44 type=auto tw=0 cols=885,9143 cm=0,0,0,0 ind=0:dxa lay=autofit bd=single:auto:4:0 hdr=0 tcm=90,195,90,195 va=center -->
| 功能 | 核心逻辑描述 |
| --- | --- |
| 列表 | 1. 接收请求从前端，不需要任何负载。 2. 查询数据库中所有高血压专项档案的分页数据。 3. 返回包含高血压档案列表的响应，如果未找到数据返回404状态码。 |
| 详情 | 1. 接收请求并获取路径参数中的ID。 2. 根据ID查询数据库中的具体高血压档案详细信息。 3. 如果查询成功，返回包含详细信息的响应；如果未找到对应记录，返回404错误。 |
| 随访记录 | 1. 接收请求并获取路径参数中的ID，该ID为管理编号。 2. 根据管理编号查询对应的高血压随访记录。 3. 返回查询到的随访记录列表，如果未找到记录，返回404错误。 |
| 随访记录详情 | 1. 接收请求并获取路径参数中的ID，该ID为随访记录的ID。 2. 根据随访记录ID查询具体的随访详情。 3. 返回随访详情的响应，如果未找到对应的随访记录，返回404错误。 |
| 历史测量 | 1. 接收患者ID作为参数。 2. 从数据库检索患者所有测量记录。 3. 根据检查种类代码（血压、血糖、血脂）分类处理数据： - 血压：创建或更新趋势图血压对象，包括收缩压和舒张压。 - 血糖：直接添加新的血糖视图对象到列表。 - 血脂：根据批次号管理血脂数据，创建或更新血脂视图对象，包括总胆固醇、甘油三酯、高密度和低密度脂蛋白。 4. 数据结构化后，将各类型的视图对象列表设置到趋势图视图对象中。 5. 返回包含所有相关趋势图数据的视图对象。 |
