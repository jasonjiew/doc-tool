#### 核心逻辑

<!-- TBL:style=45 type=pct tw=5000 cols=1252,8602 cm=0,108,0,108 ind=0:dxa lay=fixed bd=single:auto:4:0 va=center -->
| 功能 | 核心逻辑描述 |
| --- | --- |
| 查看列表 | 从sys_drug_info表中读取所有药品信息。 展示药品列表。 |
| 搜索 | 接收来自前端的搜索关键词。 在sys_drug_info表中执行关键词搜索。 返回匹配的药品信息。 |
| 新增 | 接收新药品信息。 验证药品信息的完整性和正确性。 将新药品信息存储到sys_drug_info表。 返回操作结果。 |
| 编辑 | 接收编辑请求和药品信息。 在sys_drug_info表中查找并验证药品存在。 更新药品信息。 返回编辑成功的消息。 |
| 导入 | 接收并验证导入文件的格式和内容。 将数据批量导入到sys_drug_info表。 返回导入成功的消息。 |
|  |  |
