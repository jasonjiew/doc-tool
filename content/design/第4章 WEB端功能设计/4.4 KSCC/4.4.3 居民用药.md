#### 核心逻辑

<!-- TBL:style=45 type=pct tw=5000 cols=1252,8602 cm=0,108,0,108 ind=0:dxa lay=fixed bd=single:auto:4:0 va=center -->
| 功能 | 核心逻辑描述 |
| --- | --- |
| 查看列表 | 从patient_pharmacy表中读取所有居民信息。 展示居民列表。 |
| 搜索 | 接收来自前端的搜索关键词。 在patient_pharmacy表中执行关键词搜索。 返回匹配的居民信息。 |
| 查看详情 | 根据居民ID获取详细信息。 从patient_pharmacy和patient_pharmacy_record表中聚合详细数据。 展示居民的详细信息。 |
| 新增居民 | 接收新居民信息。 验证居民信息的完整性和正确性。 将新居民信息存储到patient_info表。 返回操作结果。 |
| 新增测量记录 | 接收新测量记录信息。 验证测量记录的完整性和正确性。 将新测量记录信息存储到device_check_data_record、device_check_data_index表。 返回操作结果。 |
| 新增药品记录 | 接收新药品记录信息。 验证药品记录的完整性和正确性。 将新药品记录信息存储到patient_pharmacy_record表。 返回操作结果。 |
| 推送逻辑 | 通过添加居民用药，发送居民用药指导短信 |
