#### 核心逻辑

<!-- TBL:style=44 type=auto tw=0 cols=4320,4320 cm=0,108,0,108 ind=0:dxa lay=autofit bd=single:000000:8:0 -->
| 功能 | 核心逻辑描述 |
| --- | --- |
| 新增证书 | 校验设备是否存在；仅允许已吊销/已过期/即将过期证书重新生成；生成成功后旧证书更新为已吊销；下载zip文件。 |
| 吊销证书 | 校验状态为待分发或已安装；填写吊销原因；更新状态为已吊销；写入EMQX黑名单；立即生效。 |
| 注销证书 | 仅允许已吊销或已过期状态注销；标记为已注销；默认列表隐藏；不删除数据库记录。 |
| 证书下发 | 生成部署记录；MQTT下发凭证；监听设备回执；更新写入状态；支持失败重试机制。 |
| 生命周期统计 | 按状态统计数量；即将过期/已吊销/已过期状态标红展示。 |
| 证书缓存读取 | 新增证书、下载证书、系统分发补建、安装确认兜底均会读取 Redis 证书缓存 `gl:cert:{deviceSn}`，缓存字段 包括 `status`、`rootCa`、`deviceCert`、`deviceKey`、`password`；缓存完整后才允许继续落库或文件生成。 |
| 证书缓存生成 | 新增或系统分发触发证书生成时，先清理设备旧证书缓存，再重新生成 Root CA、设备证书、私钥和动态 Token， 并一次性写入 Redis，避免设备拿到半截证书链。 |
| 吊销缓存清理 | 设备证书吊销成功后同步清理 Redis 中的 `password` 动态 Token，并将缓存状态置为已吊销；Redis 清理失败时 抛出异常触发事务回滚，避免数据库已吊销但设备仍可继续使用旧凭据。 |
| 安装确认兜底 | 设备上报安装成功后优先按当前部署记录同步 MySQL 状态；当部署记录缺失时，允许从完整 Redis 证书缓存补建 部署快照，避免设备回执晚到、乱序或补发导致状态无法落库。 |
