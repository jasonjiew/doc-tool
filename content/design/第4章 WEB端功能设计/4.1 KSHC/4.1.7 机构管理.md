#### 核心逻辑

<!-- TBL:style=44 type=auto tw=0 cols=1108,8920 cm=0,0,0,0 ind=0:dxa lay=autofit bd=single:auto:4:0 hdr=0 tcm=90,195,90,195 va=center -->
| 功能 | 核心逻辑描述 |
| --- | --- |
| 创建 | 1. 接收来自前端的JSON数据负载。 2. 对输入数据进行验证，检查所有必填字段是否完整且有效。 3. 将数据插入到指定的数据库表中。 4. 返回成功消息和新创建机构的ID（或其他标识）。 |
| 机构树 | 1. 执行数据库查询，获取所有部门列表，根据部门名称进行模糊匹配（如果提供）。 2. 获取当前用户有权限访问的部门ID列表。 3. 筛选和排序用户有权限的部门。 4. 为每个部门创建树节点，包括部门ID、父部门ID、部门名称、排序权重，并标记无权限部门。 5. 如果提供了部门名称，返回列表形式的部门数据；否则，构建树形结构，以当前登录用户的上级部门ID作为根节点。 6. 返回构建的机构树列表。 |
| 更新 | 1. 接收更新请求和JSON数据负载，其中包含要更新的字段和新的值。 2. 在数据库中查找对应ID的机构记录。 3. 验证输入数据的有效性。 4. 更新数据库中的机构记录。 5. 返回更新成功的消息。 |
| 搜索 | 1. 接收机构名称作为搜索参数。 2. 执行搜索操作，查找匹配的机构名称。 3. 返回匹配的机构列表，并展开对应的机构树层级。 |
| 导入 | 从Excel文件中导入机构信息的功能。具体步骤如下： 读取Excel文件：从输入流中读取Excel文件的内容。 解析数据：逐行解析Excel文件中的数据，生成SysDeptImportBo对象列表。 数据校验： 检查标题栏是否正确。 检查机构编码和名称是否为空、是否超过最大长度。 检查机构编码是否有重复。 检查机构树形结构是否合法，根节点是否在系统中存在。 检查导入的机构编码是否已经存在于系统中。 插入数据：将校验通过的数据插入数据库，并维护机构关系。 更新父机构和关联关系：更新父机构ID和机构关联关系。 |
