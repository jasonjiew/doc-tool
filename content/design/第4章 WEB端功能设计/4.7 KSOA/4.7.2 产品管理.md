#### 核心逻辑

<!-- TBL:style=45 type=pct tw=5175 trh=2248 cols=2415,7784 cm=0,108,0,108 ind=0:dxa lay=fixed bd=single:auto:4:0 va=center -->
| 功能 | 描述 |
| --- | --- |
| 新增 | 通过传入的dto.getCode()获取产品编码是否存在，如果存在则返回失败信息"编码已存在"。 如果产品编码不存在，则创建一个新的SysProduct对象。 使用BeanUtils.copyProperties()方法将dto对象的属性值复制到sysProduct对象中。 如果dto对象中的links列表不为空，则将links列表中的元素通过逗号连接成一个字符串，并将其赋值给sysProduct对象的link属性。 最后，调用baseMapper.insert(sysProduct)方法将sysProduct对象插入到数据库中，并返回保存成功的信息。 |
| 列表 | 查询出所有confType为PRODUCT_MENU_TYPE_TENANT的SysProductMenu对象，得到可用的产品ID列表。 根据产品ID将SysProductMenu对象分组，存储在Map<Long, List<SysProductMenu>>中。 根据sysProduct查询所有SysProduct对象。 遍历所有SysProduct对象，创建对应的ProductInfoVo对象，并将SysProduct属性复制到ProductInfoVo对象中。 根据产品ID判断该产品是否已开通，将结果存储在isOpen属性中。 如果SysProduct对象的link属性不为空，将其按逗号分隔并转换为列表，存储在links属性中。 根据产品ID查询对应的SysProductMenu对象列表，将菜单ID转换为列表，存储在menuIds属性中。 将ProductInfoVo对象添加到结果列表中。 返回包含结果列表的R对象。 |
|  |  |
| 编辑 | 根据传入的SysProductDto对象创建一个新的SysProduct对象，并使用BeanUtils.copyProperties方法将Dto对象的属性值复制到SysProduct对象中。然后，如果Dto对象中的links列表不为空，则将列表中的元素拼接成字符串，并设置到SysProduct对象的link属性中。最后，调用baseMapper的updateById方法更新SysProduct对象，并返回操作结果。 |
| 分配菜单 | 接收产品ID和菜单ID列表的请求。 更新sys_product_menu表，以映射产品与菜单之间的关系。 返回分配成功的消息。 |
